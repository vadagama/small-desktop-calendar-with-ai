# Small Desktop Calendar

Десктоп-клиент календаря Small для macOS: календарь с настраиваемыми
представлениями слева и AI-ассистент справа. Ассистент помогает подобрать общее
время, подготовить встречи и проанализировать запланированное время.

## Состояние проекта

Цели и границы первой версии согласованы на этапе discovery 28 октября 2026 года.
Спецификация подготовлена для ревью. Код приложения, зависимости и команды
запуска, сборки и тестирования ещё не добавлены.

- [Результаты discovery](docs/discovery.md) — подтверждённые цели, сценарии и ограничения.
- [Спецификация первой версии](docs/spec-v1.md) — требования, критерии приёмки и открытые вопросы.

Направление для AI-харнеса — TypeScript; рассматриваются GLM и DeepSeek Flash.
Конкретные модели, провайдер, харнес и десктопная оболочка ещё не выбраны.
Прежнее упоминание Rust в README не было утверждённым решением.

Существующий календарь: [team.small.kz/calendar](https://team.small.kz/calendar).
