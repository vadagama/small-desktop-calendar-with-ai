# Small Desktop Calendar

Десктоп-клиент календаря Small для macOS с настраиваемым рабочим пространством:
виджеты календаря и AI-ассистента можно размещать в любой области окна
и менять их размеры перетаскиванием границ. Ассистент помогает подобрать общее
время, подготовить встречи и проанализировать запланированное время.

## Состояние проекта

Цели и границы первой версии согласованы на этапе discovery 28 октября 2026 года.
Спецификация подготовлена для ревью. Реализованы T01–T03: локальное окно
Electron и диалог через Vercel AI SDK с безопасным синтетическим инструментом,
streaming и отменой. Упакованная arm64 `.app` проверена на macOS 15.1.
Реализованы вход Small и чтение календаря; реальная интеграционная проверка
остаётся открытой. Для проверки UI добавлен
отдельный [интерактивный React-стенд](docs/prototypes/ui-validation.md) в `prototype/`.
Запуск: `cd prototype`, `npm ci`, `npm run dev`; адрес http://127.0.0.1:5173.
Все люди, встречи и ответы ассистента в стенде демонстрационные.

Из корня репозитория на Node.js ≥22.12.0: `npm ci`, затем `npm run dev`
для запуска Electron. Локальная упаковка: `npm run package:mac`; результат —
`release/Small Calendar-darwin-arm64/Small Calendar.app`.
Иконка приложения: `build/app.icns` для macOS-сборки,
`prototype/public/app-icon.png` для окна и Dock, `prototype/public/favicon.svg`
для локального интерфейса и UI-стенда.
В чате можно проверить «Сложи 2 и 3», неверные аргументы, «Ошибка модели» и отмену.
Ключи для локального режима не нужны. Полная интеграция календаря пока впереди.

Проверки: `npm test`, `npm run typecheck`, `npm run build`, `npm run format:check`,
`npm run build:desktop`, `npm run test:desktop`.
`build` компилирует ядро/тесты в `dist/`, `build:desktop` — приложение в `out/`.

Направление для AI-харнеса — TypeScript; рассматриваются GLM и DeepSeek Flash.
Доступ к моделям — Small vLLM либо персональный OpenAI-совместимый endpoint.
Для харнеса принят Vercel AI SDK (Core + UI), см. ADR-003.
Electron + React + Dockview Community приняты пользователем в ADR-002.
Dockview интегрирован в T07; desktop переиспользует календарную сетку UI-стенда.
Первая целевая система — macOS 15.1 на Apple Silicon.

### Профиль модели (T04)

Шестерёнка «Настройки модели» в панели ассистента позволяет выбрать Small vLLM
или персональный OpenAI-compatible сервис. Для Small предзаполнены
`https://ai.skiftrade.kz/v1` и `vllm/glm-5.3-flash`. Введите свой API-ключ
непосредственно в приложении и нажмите «Сохранить и использовать».
Ключ хранится в macOS Keychain; JSON содержит только параметры профиля и
ссылки на записи. При смене origin нужен новый ключ. Для автономной проверки
есть явная кнопка «Локальная проверка»; автоматического fallback нет.
Реальная GLM требует отдельной проверки с вашим ключом.

[Проверки и ограничения T04](docs/implementation/t04-llm-profiles.md).

### Вход в Small (T05)

Кнопка «Профиль Small» внизу левой панели открывает форму входа. Введите
свои данные непосредственно в приложении. Сессия хранится в Keychain, пароль
не сохраняется, токены не передаются ассистенту. Доступны проверка сессии
и выход; восстановление после перезапуска выполняется через refresh.
Реальный вход Small и изоляция двух реальных аккаунтов требуют проверки.

[Проверки и ограничения T05](docs/implementation/t05-small-login.md).

### Чтение календаря (T06)

После входа desktop читает личные или выбранные публичные календари Small.
Доступны день, неделя, месяц и карточка события; часовой пояс — `Asia/Almaty`.
Мини-календарь в боковой панели выбирает дату; стрелки над ним листают только
месяц мини-календаря. Вкладка «Календарь» включает личные события,
«Переговорные» открывает существующий список публичных календарей Small.
Отдельного признака типа помещения в текущем контракте нет.
Пустой период, отсутствие прав и неполные данные показаны отдельно.
Для повторного чтения нажмите «Обновить». Демонстрационные встречи в desktop
не подставляются; запись встреч пока не подключена. Сверка с реальными встречами Small остаётся открытой.

[Проверки и ограничения T06](docs/implementation/t06-calendar-read.md).

### Компоновка рабочего пространства (T07)

Кнопка «Настройки пространства» внизу левой панели открывает выбор положения
ассистента: справа, слева, сверху или снизу, как в UI-прототипе. Заголовки
также можно перетаскивать к краям другой панели. Кнопка в заголовке календаря
«Поменять панели местами» сохраняет ось компоновки; границу можно двигать
мышью, а кнопки −/+ в настройках меняют размер ассистента с клавиатуры. История чата,
черновик, потоковый ответ и выбранный период сохраняются при перемещении.
После перезапуска компоновка возвращается к исходной; постоянное сохранение
ещё требует согласования.

[Проверки и ограничения T07](docs/implementation/t07-workspace-layout.md).


### Подбор общего времени (T08, частично)

После входа нажмите «Подобрать время» в заголовке окна. Найдите и выберите
всех участников, включая себя, затем задайте дату и длительность (по умолчанию
30 минут). Диалог показывает варианты Small на выбранный рабочий день в Алматы
после проверки индивидуальной занятости. Неполные данные и отказ доступа
не считаются свободным временем. Встреча при этом не создаётся.

[Проверки и ограничения T08](docs/implementation/t08-availability.md).
Подбор доступен также из AI-чата с выбранным LLM-профилем: найдите сотрудников,
затем отправьте `Участники: [ID1, ID2]`, дату и длительность отдельным сообщением.
Результаты поиска и слоты передаются выбранной модели. Каждый запрос независим.
[Проверки и ограничения AI-чата](docs/implementation/t08-assistant-tools.md).
Реальная интеграция и полный состав команды остаются открытыми.
