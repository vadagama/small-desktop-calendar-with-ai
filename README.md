# Small Desktop Calendar

Десктоп-клиент календаря Small для macOS с настраиваемым рабочим пространством:
виджеты календаря и AI-ассистента можно размещать в любой области окна
и менять их размеры перетаскиванием границ. Ассистент помогает подобрать общее
время, подготовить встречи и проанализировать запланированное время.

Память ассистента открывается кнопкой с мозгом в боковом меню: предпочтения
встреч, текстовые записи контекста, группы и форматы. Изменения из чата требуют
подтверждения. Данные хранятся локально для аккаунта и переживают перезапуск;
история чатов остаётся в бэклоге. [Устройство и проверки памяти](docs/implementation/assistant-memory.md).

## Состояние проекта

Цели и границы первой версии согласованы на этапе discovery 28 октября 2026 года.
Спецификация подготовлена для ревью. Реализованы T01–T03: локальное окно
Electron и диалог через Vercel AI SDK с безопасным синтетическим инструментом,
streaming и отменой. Упакованная arm64 `.app` проверена на macOS 15.1.
Реализованы вход Small и чтение календаря; реальная интеграционная проверка
остаётся открытой. Для проверки UI добавлен
отдельный [интерактивный React-стенд](docs/prototypes/ui-validation.md) в `prototype/`.
Запуск: `cd prototype`, `npm ci`, `npm run dev`; адрес http://127.0.0.1:5173.
Все люди, встречи и ответы ассистента в стенде демонстрационные.

Из корня репозитория на Node.js ≥22.12.0: `npm ci`, затем `npm run dev`
для запуска Electron. Локальная упаковка: `npm run package:mac`; результат —
`release/Small Calendar-darwin-arm64/Small Calendar.app`.
Иконка приложения: `build/app.icns` для macOS-сборки,
`prototype/public/app-icon.png` для окна и Dock, `prototype/public/favicon.svg`
для локального интерфейса и UI-стенда.
В чате можно проверить «Сложи 2 и 3», неверные аргументы, «Ошибка модели» и отмену.
Ключи для локального режима не нужны. Полная интеграция календаря пока впереди.

Проверки: `npm test`, `npm run typecheck`, `npm run build`, `npm run format:check`,
`npm run build:desktop`, `npm run test:desktop`.
`build` компилирует ядро/тесты в `dist/`, `build:desktop` — приложение в `out/`.

### Профиль модели (T04)

Шестерёнка «Настройки модели» в панели ассистента позволяет выбрать Small vLLM
или персональный OpenAI-compatible сервис. Для Small предзаполнены
`https://ai.skiftrade.kz/v1` и `vllm/glm-5.3-flash`. Введите свой API-ключ
непосредственно в приложении и нажмите «Сохранить».
Ключ хранится локально в зашифрованном файле; JSON профиля содержит только
метаданные и маску с последними четырьмя символами. Зелёная галочка означает,
что локальный профиль сохранён, выбран и нет несохранённых изменений. Она не
означает проверку авторизации у провайдера. Сохранение без нового ключа не
перезаписывает секрет.
«Удалить ключ» удаляет ключ и профиль. При смене origin нужен новый
ключ; автоматического fallback нет.
Без активного профиля чат предлагает открыть настройки модели. Если профиль
уже сохранён, выберите его и нажмите «Сохранить» — повторный ввод ключа не нужен. Тестовый
сценарий сложения доступен только при явном `SMALL_TEST_SYNTHETIC=1`.
Реальная GLM требует отдельной проверки с вашим ключом.

[Проверки и ограничения T04](docs/implementation/t04-llm-profiles.md).

### Вход в Small (T05)

Кнопка «Профиль Small» внизу левой панели открывает форму входа. Введите
свои данные непосредственно в приложении. Сессия хранится локально в зашифрованном виде, пароль
не сохраняется, токены не передаются ассистенту. Доступны проверка сессии
и выход; восстановление после перезапуска выполняется через refresh.
Реальный вход Small и изоляция двух реальных аккаунтов требуют проверки.

[Проверки и ограничения T05](docs/implementation/t05-small-login.md).

### Чтение календаря (T06)

После входа desktop читает личные или выбранные публичные календари Small.
Доступны день, неделя, месяц и карточка события; часовой пояс — `Asia/Almaty`.
Мини-календарь в боковой панели выбирает дату; стрелки над ним листают только
месяц мини-календаря. Вкладка «Календарь» включает личные события,
«Переговорные» открывает существующий список публичных календарей Small.
Отдельного признака типа помещения в текущем контракте нет.
Пустой период, отсутствие прав и неполные данные показаны отдельно.
Для повторного чтения нажмите «Обновить». Демонстрационные встречи в desktop
не подставляются; запись встреч пока не подключена. Сверка с реальными встречами Small остаётся открытой.

[Проверки и ограничения T06](docs/implementation/t06-calendar-read.md).

### Компоновка рабочего пространства (T07)

Кнопка «Настройки пространства» внизу левой панели открывает выбор положения
ассистента: справа, слева, сверху или снизу, как в UI-прототипе. Заголовки
также можно перетаскивать к краям другой панели. Кнопка в заголовке календаря
«Поменять панели местами» сохраняет ось компоновки; границу можно двигать
мышью, а кнопки −/+ в настройках меняют размер ассистента с клавиатуры. История чата,
черновик, потоковый ответ и выбранный период сохраняются при перемещении.
После перезапуска компоновка возвращается к исходной; постоянное сохранение
ещё требует согласования.

[Проверки и ограничения T07](docs/implementation/t07-workspace-layout.md).


### Подбор общего времени (T08, частично)

Подбор доступен из AI-чата с выбранным LLM-профилем. Напишите, например:
«Создай встречу завтра после обеда с Олегом и Витей». Ассистент ищет людей,
уточняет неоднозначность и недостающие параметры, предлагает проверенные слоты.
ID и ISO-даты вводить не нужно. Диалог и результаты инструментов сохраняются
в пределах текущего чата; частые участники и подтверждённые прозвища — локально
между запусками. Кнопка «Новый диалог» начинает новый чат.
[Контекст, память и шаблоны](docs/implementation/assistant-dialogue.md).
Результаты поиска и слоты передаются выбранной модели; полнота состава команды
по одному названию не гарантируется.

### Создание встречи (T09)

После выбора времени ассистент готовит карточку с организатором, полными
именами участников, временем и ссылкой конференции. Неизвестную длительность
он уточняет. Название и адженду можно исправить в карточке.
Создание запускается отдельной кнопкой после проверки показанной версии. После
неопределённого ответа повторная отправка блокируется, доступна сверка результата.
[Поведение, журнал и ограничения проверки](docs/implementation/t09-confirm-meeting.md).

### Редактирование и удаление встречи

В меню события выберите «Редактировать», измените название и нажмите «Сохранить».
«Удалить» сразу удаляет разовую встречу без дополнительного подтверждения.
Приложение проверяет организатора; серии и их вхождения пока не поддерживаются.
[Поведение и ограничения](docs/implementation/event-card-and-drag.md).

### Создание встречи вручную

Нажмите «Создать +» в хедере. Форма поддерживает название, описание, ссылку,
участников, информируемых, переговорную, время, еженедельные повторения и файлы.
AI-профиль не нужен. Проверка занятости выполняется до записи; неизвестный результат
не отправляется повторно. [Поведение и ограничения](docs/implementation/manual-meeting-create.md).

### Инструкции и навыки AI-помощника

В заголовке чата нажмите «Настройки AI-помощника» (иконка искр), чтобы выбрать Mood (нейтральный, строгий, молодёжный, альфа, технарь), изменить пользовательские инструкции и Markdown календарных навыков, включить или отключить сценарии. Технический промпт хранится отдельно в `src/agent/content/system.md`. Настройки сохраняются между запусками; кнопка «Восстановить стандартные» возвращает встроенные значения. Подробности: [настройки AI-помощника](docs/implementation/assistant-customization.md).

Ключи и сессия Small используют AES-256-GCM и индивидуальный случайный ключ
установки. Каталог профиля закрыт правами владельца. Keychain и `safeStorage`
не используются; после перехода со старой версии нужно заново войти в Small
и сохранить API-ключ. Программа с правами вашего пользователя может прочитать
и ключ шифрования, и данные. [Устройство и границы защиты](docs/implementation/local-credential-storage.md).

### Повторяющиеся встречи (T13)

Для серии меню карточки открывает диалог области: «Только это вхождение» (по
умолчанию) или «Это и последующие», с датой и пометкой, что прошедшие встречи
не изменятся. Серверное поведение серий ещё не подтверждено проверкой на тестовой
среде, поэтому запись закрыта и причина показана в диалоге; обычные встречи
работают как раньше. [Устройство, проверки и ограничения](docs/implementation/t13-series-scope.md).

### Аналитика встреч (T12)

Спросите ассистента, например: «Сколько часов встреч у меня в этом месяце?».
Карточка отчёта показывает количество, сумму длительностей и занятое время
отдельно, регулярные встречи, группы вне итога и состав отчёта с правилами.
Числа считает код; отмены, команды и теги календарь не отдаёт, и это указано.
Кнопка «Правила тем аналитики» в боковой панели задаёт темы по ключевым словам
названия. [Правила, проверки и ограничения](docs/implementation/t12-analytics.md).

### Напоминания (T11)

Колокольчик в боковой панели открывает напоминания и настройку 0–60 минут
(по умолчанию 5). После закрытия окна они продолжают работать; Cmd+Q завершает
приложение. Системные баннеры требуют подписанной macOS-сборки и разрешения ОС.
[Поведение, проверки и ограничения](docs/implementation/t11-reminders.md).

Для реальных уведомлений на этом Mac: `npm run package:mac:local`, затем
`open 'release/Small Calendar-darwin-arm64/Small Calendar.app'`.
В колокольчике доступна кнопка «Отправить тестовое уведомление» с проверкой
истории доставки macOS. Это локальная ad-hoc сборка, не релиз для распространения.
[Проверки и ограничения подписи](docs/implementation/macos-notification-delivery.md).
