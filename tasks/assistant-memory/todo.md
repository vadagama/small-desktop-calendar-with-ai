Статус активных задач M01–M09 и M14–M18: реализованы; итоговая проверка ниже. [Требования](../../docs/proposals/assistant-memory.md),
[план](plan.md). Каждый пункт — отдельный проверяемый срез. Указанные пути новых
модулей/тестов являются предложением; при разрастании свыше пяти файлов разделить
задачу перед реализацией. M — средний срез, S — малый.

M10–M13 сняты с текущего плана; их ID зарезервированы, остальные ID сохранены.
Сохранение чатов учитывается отдельно в [бэклоге](backlog.md), без зависимости
от него для групп и форматов.

Команды проверки: `npm test`, `npm run typecheck`, `npm run build:desktop`,
`npm run test:desktop`, `npm run format:check`. Для E2E можно передать путь
конкретного файла после `npm run test:desktop --`. Полная регрессия — на этапах.

## Результаты реализации

Реализация: [описание и ограничения](../../docs/implementation/assistant-memory.md).
Согласованы подтверждение кнопкой, буфер организатора и локальное хранение
после выхода до явного удаления. Чаты не включены в реализацию.

Фактическое разбиение модулей отличается от предложенных путей:
группы и форматы используют общий `src/main/memory-tools.ts` и
`src/renderer/MemoryCollections.tsx`; основной store —
`src/main/assistant-memory.ts`, подтверждения — `memory-proposals.ts`,
контракты и безопасные для sandbox preload каналы разделены.

Память хранится в существующем зашифрованном namespace LocalSecrets. Повреждение
одного конверта требует явного сброса всей памяти аккаунта; восстановление
отдельной повреждённой категории не заявляется. Календарный контракт на длину
названия/повестки сохранён: длинный формат можно хранить, перед созданием его
нужно сократить. Эти отличия и откат описаны в документации реализации.

Доказательства:

- `tests/agent/assistant-memory.test.ts`: миграция, хранение, аккаунты,
  revision/request ID, подтверждения, сбои, повреждение, потеря ключа и схемы.
- `tests/agent/memory-integration.test.ts`: применение предпочтений в main,
  следующий ход, исключения, удалённый контекст, коллизии, группы и формат.
- `tests/agent/meeting-preferences.test.ts`: приоритет по полям и явный ноль.
- `tests/agent/availability.test.ts`: перерывы, точные границы, соседние даты.
- `tests/agent/meeting-writer.test.ts`: инвалидирование перед проверкой и записью.
- `tests/desktop/assistant-memory.spec.ts`: CRUD-форма на реальном store,
  подтверждение из чата, применение формата, изменение памяти перед подтверждением
  встречи без отправки, рестарт, аккаунты, очистка, computed размеры 18/13/14 CSS px.
- Прототип: 30 браузерных тестов прошли.

Реальная LLM не проверялась; E2E использует синтетический HTTP endpoint и
синтетический Small. Это ограничение приёмки по M09; качество выбора инструментов
конкретной моделью не объявляется проверенным. Коммиты, push и релиз не выполнялись.

Итог: `npm test` — 441/441, полная Electron-регрессия — 41/41,
заключительный focused memory E2E — 1/1; `typecheck`, `build:desktop`,
`format:check`, `git diff --check` прошли. Прототип: 12 unit и 30 browser,
сборка прошла. После полного прогона дополнительно усилена очистка старых
черновиков из контекста и повторены unit/typecheck/build/focused memory E2E.
