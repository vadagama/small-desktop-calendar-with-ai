# Small Desktop Calendar

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
В текущем запросе создаётся браузерный UI-стенд. Пользователь подтвердил React-стенд по текущей спецификации.
Для стенда используются React + TypeScript + Vite в отдельной папке prototype/.
Выбор оболочки десктопного приложения остаётся на ревью в ADR-002.

## Users
Сотрудники Small, планирующие рабочие встречи; первый этап — проверка UI
инициатором проекта. Основание: docs/discovery.md.

## Product Purpose
Сократить координацию встреч: найти общее время, проверить черновик,
подтвердить встречу и увидеть её в календаре.

## Operating Context
Рабочее окно на macOS. Календарь и ассистент размещаются рядом либо друг
над другом, меняются местами; размеры меняются разделителем.
Начальный часовой пояс Asia/Almaty. Язык интерфейса — русский.

## Capabilities and Constraints
Календарь день/неделя/месяц, карточка встречи, подбор слотов и подтверждение.
Прототип использует только синтетические события и детерминированный диалог.
Нет реальной авторизации, модели, приглашений и нативных уведомлений.
Прототип не доказывает полноту API или паритет с Team Small.

## Evidence on Hand
Сценарии: docs/discovery.md; проектные критерии: docs/spec-v1.md.
Реальных встреч, персональных данных и подтверждённых бренд-ассетов нет.

## Product Principles
- Явно различать демонстрационные и реальные данные.
- Показывать параметры до подтверждения операции.
- Держать календарь и диалог в одном изменяемом пространстве.
- Ошибка и неполные данные не означают свободное время.

## Brand Commitments
Пользователь явно требует стиль дизайн-системы Small по приложенному скриншоту:
белая поверхность, компактная серо-чёрная навигация, оранжевый знак,
чёрные основные действия и голубые календарные события.

## UI approval

28.10.2026 пользователь согласовал текущий прототип как основу интерфейса для разработки («Можно этот прототип брать в работу»). Визуальные правила и взаимодействия описаны в DESIGN.md и docs/prototypes/ui-validation.md. Демо-данные и сценарии ассистента необходимо заменить рабочими интеграциями; согласование UI не утверждает десктопную оболочку и не означает готовность к production.
