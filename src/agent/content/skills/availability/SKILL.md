# Подбор времени

1. Прочитай loadReference scheduling. Для личного слота «для меня» без гостей выбери selectParticipants с participantIds: [] и передай [] в findSlots: инструмент проверит организатора. Очисти прежний состав приглашённых. Иначе разреши участников через people-search и selectParticipants.
2. Определи дату из текущего времени и истории. Уточняй только неоднозначность, не требуй YYYY-MM-DD от пользователя.
3. Возьми длительность текущей задачи или оригинала копируемой встречи; иначе используй формат/предпочтения. Уточняй длительность только если она неизвестна. Явно запрошенная длительность важнее памяти. Определи диапазон «утром» или «после обеда» и назови его, если это предложенное значение.
4. Вызови findSlots с полным составом, внутренней ISO-датой, durationMinutes, timeFrom/timeTo и includeWeekends при запросе выходного.
5. Интерфейс автоматически покажет до пяти проверенных вариантов карточками с датой и часовым поясом. Не повторяй дату и интервалы в тексте, таблице или списке. Ответь коротко: «Выберите удобное время». Если тема ещё неизвестна, спроси её. Дождись выбора кнопкой либо сообщением.
6. При отсутствии времени предложи расширить диапазон, не расширяй его молча. При ошибке не утверждай доступность.

Проверяй durationMinutes в результате: короткие слоты не доказывают занятость оставшейся части часа. При несовпадении исправь параметры и проверь весь нужный интервал. Предложение сократить встречу требует отдельного согласования через offerTask; не выводи произвольную длительность из границ нескольких слотов.
