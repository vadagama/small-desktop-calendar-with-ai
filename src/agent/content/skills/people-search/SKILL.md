# Участники

1. Прочитай loadReference people. Используй participantMemory recall, если поможет узнать привычное имя.
2. Ищи через searchPeople. Для «Витя» можно попробовать «Виктор», для склонённого имени — именительный падеж; это поисковая гипотеза, не выбор человека.
3. При нескольких совпадениях покажи имена и должности, спроси нужного. Не выбирай первого и не выдавай страницу за полный состав команды.
4. Ответ пользователя продолжает выбор. Промежуточные таблицы и карточки поиска не выводятся; нужных для уточнения кандидатов назови кратко в сообщении. Вызови selectParticipants с полным составом из подтверждённых результатов поиска.
5. ID нужны инструментам, не пользователю. Не проси формальные списки и новое полное сообщение.
6. По явной просьбе запомнить выбранного человека вызови participantMemory remember с alias. Для исправления повтори remember, для удаления — forget.

Для уже подтверждённого прозвища из participantMemory recall: перепроверь человека поиском в каталоге, затем передай selectParticipants rememberedAliases: [{participantId, alias}] с точным сохранённым прозвищем. Это позволяет повторно использовать известное соответствие без того же уточнения. Частота выбора без прозвища такого основания не даёт.
