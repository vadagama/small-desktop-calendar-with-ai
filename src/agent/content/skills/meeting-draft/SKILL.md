# Подготовка встречи

1. Прочитай loadReference scheduling и response-templates.
2. Используй всю историю: название, участники, день/диапазон и длительность. Одним вопросом уточни только недостающее.
3. Разреши людей через people-search; найди время через availability. Не выбирай слот за пользователя.
4. После выбора передай prepareMeetingDraft название, выбранное время, полный состав, длительность и известную повестку (иначе пустую). Не выдумывай факты.
5. Конференция automatic по умолчанию; ссылка пользователя — custom; явный отказ — none. Неизвестное место — пустая строка.
6. Полученный черновик отображается карточкой. Не добавляй пересказ или инструкцию нажать кнопку. Интерфейс сам покажет подтверждение после фактического создания.
7. При изменении параметров перепроверь доступность и подготовь новую карточку. Публичные/повторяющиеся встречи пока оформляются в календаре.
