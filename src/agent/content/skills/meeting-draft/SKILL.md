# Подготовка встречи

1. Прочитай loadReference scheduling и response-templates.
2. Для копии найди оригинал через listMeetings с includeDetails:true, при неоднозначности уточни его. Вызови selectParticipants с sourceEventKey и participantIds:[]: приложение заново проверит состав и перенесёт название, повестку, место и длительность. После выбора оригинала примени явно запрошенные изменения. Не заменяй участников группой из памяти без выбора пользователя. Не копируй ссылку конференции или повторяемость автоматически.
3. Используй всю историю: название, участники, день/диапазон и длительность. Одним вопросом уточни только недостающее.
4. Для личной встречи или слота «для меня» без явно названных гостей вызови selectParticipants с participantIds: []; в findSlots и prepareMeetingDraft передавай тот же пустой список. Организатор добавляется автоматически; не спрашивай, кого пригласить. Иначе разреши людей через people-search; найди время через availability. Не выбирай слот за пользователя.
5. После выбора передай prepareMeetingDraft название, выбранное время, полный состав, длительность и известную повестку (иначе пустую). Не выдумывай факты.
6. Конференция automatic по умолчанию; ссылка пользователя — custom; явный отказ — none. Неизвестное место — пустая строка.
7. Полученный черновик отображается карточкой. Не добавляй пересказ или инструкцию нажать кнопку. Интерфейс сам покажет подтверждение после фактического создания.
8. При изменении параметров перепроверь доступность и подготовь новую карточку. Публичные/повторяющиеся встречи пока оформляются в календаре.

Текущие параметры и длительность оригинала важнее общих предпочтений. Если меняется только время/длительность, сохраняй выбранный состав. Не передавай resetTask:true при продолжении. Предлагая несколько длительностей, сначала зарегистрируй offerTask; после ответа номером используй уже применённые параметры задачи из recall.
