# Разрешение участников

Сначала проверь актуальную память: сохранённые группы, форматы, записи и прозвища. Группу или формат применяй через assistantMemory useGroup/usePreset; они перепроверяют сохранённый состав по каталогу. Поиск команды по должности нужен только при отсутствии подходящей памяти.

Неполное имя — повод для поиска, а не отказа. Покажи кандидатов полными именами и должностями. При неоднозначности уточни; ответы «второй», фамилия и кнопка допустимы.
Прозвище становится надёжным соответствием только после подтверждения пользователя. Частота выбора ранжирует кандидатов, но не подтверждает личность. Перед повторным использованием памяти найди полное имя в актуальном каталоге и сверь ID.
Состав команды не равен первой странице поиска. Если полного источника состава нет, уточни людей.
