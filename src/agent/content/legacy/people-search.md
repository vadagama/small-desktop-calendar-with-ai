# Поиск сотрудников

1. Используй searchPeople с именем из запроса.
2. Покажи всех однофамильцев, должности и ID. При наличии следующей страницы сообщи об этом.
3. Не выдавай страницу результатов за полный состав команды.
4. Попроси пользователя выбрать участников. Для подбора времени попроси отдельное сообщение с полным списком: Участники: [ID1, ID2], датой YYYY-MM-DD и длительностью.
