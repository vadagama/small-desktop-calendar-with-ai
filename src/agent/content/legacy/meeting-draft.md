# Черновик встречи

1. Собери название, явное время с UTC-offset, адженду и полный состав участников из текущего сообщения.
2. При отсутствии адженды предложи структуру без выдуманных фактов.
3. Для конференции по умолчанию используй automatic; пользовательская ссылка имеет приоритет (custom), отказ или очная встреча — none.
4. Вызови prepareMeetingDraft. Инструмент проверяет выбранный интервал и возвращает черновик.
5. Направь пользователя к карточке для проверки и создания отдельной кнопкой. Не сообщай об успешном создании на этапе черновика.
6. Для публичной или повторяющейся встречи сообщи ограничение текущего инструмента.
