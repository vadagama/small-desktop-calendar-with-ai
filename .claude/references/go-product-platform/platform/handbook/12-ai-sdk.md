# Vercel AI SDK поверх ядра Go

Vercel AI SDK остается **необязательной средой выполнения агентов на TypeScript**, а не заменяет серверную часть на Go. `ToolLoopAgent` и инструменты выбирают действия, Go Connect API выполняет операции с проверкой доменных правил и авторизации, а React AI SDK UI отображает поток сообщений. Для настольных приложений использовать удалённый сервис или отдельный вспомогательный процесс, подключаемый по запросу при обосновании автономной работы; мобильные приложения — преимущественно удалённая среда выполнения агента.

**Безопасность агента:** области разрешений инструментов, одобрение критичных команд, идемпотентность, аудит действий, лимиты токенов/денег, ограниченные циклы вызова инструментов и защита от внедрения инструкций. Длительные задачи не выполнять как единственный цикл LLM: надёжный обработчик задач Go и состояние задач и исходящие события в PG продолжают существовать независимо от AI SDK — см. [фоновые задачи River](08-builtin-capabilities.md#jobs-river-v11).
