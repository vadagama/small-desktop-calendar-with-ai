# Шаблоны UI/UX

Копировать при разработке целевого UI, не создавать пустой пакет при настройке
только инструментов. Правила и критерии —
[общий UI-процесс](../../references/prototyping-installation.md#документация-целевого-ui).

| Шаблон | Путь в продукте |
|---|---|
| [DESIGN.md](DESIGN.md) | `docs/ui/DESIGN.md` |
| [vision.md](vision.md) | `docs/ui/<имя инженерной SPEC>/vision.md` |
| [components.md](components.md) | `docs/ui/<имя инженерной SPEC>/components.md` |
| [screens.md](screens.md) | `docs/ui/<имя инженерной SPEC>/screens.md` |

Заменить пример SPEC-0001 на реальный номер, сохранить уникальность ID, добавить
ссылки на инженерную SPEC и источники решений. Оставить draft до содержательной
проверки. Общие правила не копировать из DESIGN.md в каждый документ фичи.
