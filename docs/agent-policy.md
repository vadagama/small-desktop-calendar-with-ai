# Область платформы

Профиль custom описывает существующее приложение Go/Wails, React и Vercel AI SDK. Контракты и авторизация календаря принадлежат сервису Small. Изменения транспорта, хранилища и API требуют отдельного решения по архитектуре. Используйте изолированные профили и скрытый режим для нативных тестов.
