# Ревью первого среза

Независимый анализ выполнен для рабочей копии на `776bdd5` с локальными изменениями. Проверены обработка отказа авторизации, границы Wails bindings и соответствие объёма проверок критериям этапа.

Замечания по чтению кеша после 403 и истечения cookie исправлены. Явный отказ источника инвалидирует его запись, отказ в доступе к профилю очищает сессию и сообщает интерфейсу о необходимости повторного входа. Для деталей события добавлен узкий маршрут чтения. Зарезервированные маршруты отклоняются. Финальный прогон Go с `-race` и нативным тестом прошёл.

Для сравнения использованы интерфейсные сценарии, размеры viewport и вычисленные стили. Размеры локальных образов записаны как промежуточные, поскольку комплект поставки различается. Подробности и ограничения приведены в [проверке](verification.md).
