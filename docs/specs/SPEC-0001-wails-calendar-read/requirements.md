# Первый срез Wails — вход и чтение календаря

Целевая платформа первого среза — macOS arm64, как в текущей сборке. Использовать синтетический Small API и отдельный профиль.

| Критерий | Исходный контракт | Приёмка |
| --- | --- | --- |
| AC-001 | React UI, стили, Dockview и правило чистого запуска в AGENTS.md | Чистый профиль открывает текущий UI. Сравнить форму входа, календарь и пустые настройки Electron и WKWebView на одном viewport и масштабе. Проверить типографику, клавиатуру и компоновку |
| AC-002 | Вход, refresh и выход по ADR-005 | Проверить тестовый вход, восстановление сессии после перезапуска, отказ refresh и выход. Пароль применяется только при входе |
| AC-003 | Чтение, фильтры, offline-cache и изоляция аккаунтов | Одинаковые события и фильтры на общих фикстурах. Файловый кеш переживает перезапуск, offline показывает кеш, смена аккаунта исключает выдачу чужих событий |
| AC-004 | Цели инициативы | Зафиксировать исходные измерения и замеры первого среза. Приоритет — размер полного DMG, ориентир до 15 МБ. Для сопоставимой сборки сравнить одинаковый функциональный объём |

Запись встреч, импорт реального профиля, подключение существующего ассистента и интеграции macOS относятся к следующим этапам. Ассистент сохраняет текущий рантайм Vercel AI SDK и интерфейс чата. Замеры первого среза без ассистента считаются промежуточными.
