# Порядок реализации

Снять эталон Electron для одинаковых синтетических сценариев. Затем проверить существующий renderer в WKWebView и подключить вход и чтение через Go. Следом проверить файловый кеш на рестарте и смене аккаунта. Перед следующим этапом сравнить интерфейс и контракты, записать замеры и провести ревью. Каждый запуск использует собственный чистый профиль.
