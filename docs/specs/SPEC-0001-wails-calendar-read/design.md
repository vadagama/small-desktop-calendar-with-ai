# Устройство первого среза

Один renderer используется в Electron и Wails. TypeScript-адаптер Wails сохраняет формы данных, ошибки и подписки действующего интерфейса для входа и чтения. В Go отдельно реализуются клиент Small, сессия и чтение календаря. Wails вызывает эти сервисы через узкие bindings.

Зашифрованные файлы обслуживают кеш в новом профиле. Ключ кеша учитывает аккаунт и диапазон/параметры чтения. Сквозные проверки используют синтетический API. Пароль используется при входе, а ключи моделей хранятся отдельно от кеша. Старый профиль остаётся пригодным для запуска Electron.
