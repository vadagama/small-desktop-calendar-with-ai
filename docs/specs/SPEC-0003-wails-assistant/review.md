# Ревью

Независимый ревьюер проверил рабочую копию от `776bdd5`. Запуск и обращения к памяти и доступности теперь привязаны к поколению сессии до записи IPC-кадра. Node проверяет свою ревизию при записи памяти и учитывает отмену, пришедшую перед стартом. Запись в канале ограничена по времени. Go проверяет окно предпочтительного времени и буфер организатора при подтверждении черновика.

При повторной проверке исходников ревьюер подтвердил привязку операций к поколению сессии и применение границ времени к каждому вхождению. [Результаты тестов](verification.md).
