# Ассистент в Go и Wails

| Критерий | Ожидаемый результат |
| --- | --- |
| AC-001 | Текущий React-чат с тем же Vercel AI SDK отображает поток, ошибки и остановку. Профили модели, инструкции и навыки обслуживаются существующими TypeScript-модулями |
| AC-002 | Инструменты ассистента обращаются к календарю через Go с текущими правами Small. Календарные записи требуют подтверждения в интерфейсе |
| AC-003 | Изменения памяти из чата требуют подтверждения и сохраняются для нужного аккаунта. Профиль модели и память переживают перезапуск локального процесса |
| AC-004 | Локальный arm64 DMG запускается в чистом профиле со встроенным рантаймом. Размер измерен для сравнения с ориентиром 15 МБ |
