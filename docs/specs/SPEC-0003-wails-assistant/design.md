# Подключение

React использует тот же контракт `smallDesktop` и получает через Wails сообщения, которые выпускает существующий рабочий модуль AI SDK. Go запускает Node.js по запросу и держит закрытый канал обмена. Node загружает прежние инструменты, инструкции, профили моделей и файловую память. У Electron и Wails раздельные профили.

На каждом обращении от Node Go проверяет ревизию сессии, владельца и допустимую операцию. Инструмент может прочитать календарь, получить доступность или передать черновик в Go. Подтверждение в интерфейсе запускает стандартные команды записи. Изменения памяти проверяет существующая карточка подтверждения и привязка к аккаунту.

Остановка запроса отменяет работу инструмента и потока. Завершение приложения останавливает дочерний процесс. Следующий запрос восстанавливает процесс после сбоя. Предварительный пакет использует полный бинарник Node.js в `Contents/Resources`.
