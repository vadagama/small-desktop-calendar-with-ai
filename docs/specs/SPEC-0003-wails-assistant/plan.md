# План этапа

Вынести запуск общего рабочего модуля ассистента из зависимости от Electron. Подключить хранилища и поток событий через Wails, затем ограничить доступ инструментов к операциям календаря в Go. Сравнить сценарии двух оболочек на синтетическом сервере и проверить реальное подключение DeepSeek коротким запросом без данных календаря. Завершить проверкой чистого старта собранного DMG и замером размера. Для возврата к исходной оболочке использовать Electron с его отдельным профилем.
