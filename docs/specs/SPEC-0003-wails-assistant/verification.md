# Проверки

Рабочая копия от `776bdd5`, macOS 27.2.1 arm64, Go 1.26.10, Wails 3.0.0 и Node.js 22.23.2. Обе оболочки запускались в фоне с отдельными временными профилями.

| Критерий | Результат |
| --- | --- |
| AC-001 | Скрытый WKWebView отобразил ответ из рабочего модуля AI SDK, остановку и сообщение об ошибке модели. Отдельный запрос к DeepSeek вернул текстовый поток. В запросе был только синтетический текст |
| AC-002 | Синтетическая модель запросила список встреч. Go прочитал календарь, а результат получил React и следующий шаг модели. Модель подготовила черновик встречи, и Go отправил ровно один POST после подтверждения. Проверен отказ для маршрутов записи в канале чтения |
| AC-003 | Проверены пустая память нового аккаунта, карточка изменения, отсутствие записи до подтверждения, сохранение после подтверждения, повторное открытие профиля после перезапуска и восстановление после принудительной остановки Node.js. Повтор карточки после выхода отклонён |
| AC-004 | Локальный DMG с ad-hoc подписью проверен `codesign` и `hdiutil verify`. Приложение прошло скрытый старт с чистым профилем и системным `PATH` без Node.js. В 4 файлах пакета проверено отсутствие `.env` и известных значений секретов |

Прошли `npm test` (580/580), `npm run typecheck`, отдельная строгая проверка TypeScript адаптера, сборки Electron и Wails, `SMALL_WAILS_WEBVIEW_TEST=1 go test -race -count=1 -v ./...` (10 верхнеуровневых тестов) и `go vet ./...`. Семь фоновых сценариев Electron прошли и охватили чат, настройки модели, навыки, память, календарные инструменты и панель доступности. В последнем сценарии дата синтетической недели обновлена до будущей с сохранением расположения дней и проверок вёрстки.

DMG `release/wails-assistant-stage/wails-assistant-stage.dmg` занимает 48 234 950 байт (48,2 МБ). Вложенный бинарник Node.js занимает 112 261 952 байта до сжатия. Ориентир 15 МБ остаётся для полной сборки.

Проверки записи выполнялись на локальном API. Для итоговой поставки предстоят проверка macOS 15.1, подпись Developer ID и notarization, голос, напоминания, обновления, сверка интерфейса и перенос действующих профилей.
