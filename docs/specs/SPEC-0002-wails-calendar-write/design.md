# Контракты записи

Go принимает отдельные типизированные вызовы для операций и проверяет доступ перед обращением к API Small. Адаптер Wails сохраняет интерфейс `smallDesktop`. Для ответа на приглашение кеш сбрасывается перед PATCH, а действующий React-компонент инициирует обновление после подтверждения. Журналы операций создания, редактирования и серий переносятся отдельными срезами.
