# Проверки

Приёмка на рабочей копии от `776bdd5`, macOS 27.2.1 arm64, Go 1.26.10, Wails 3.0.0. Все записи выполнялись через локальные синтетические API.

| Критерий | Доказательство |
| --- | --- |
| AC-001 | Обе кнопки RSVP проверены в скрытом WKWebView и в Electron. Сервер видит один PATCH на действие. Проверены чужой аккаунт, участие, допустимый статус и отказ без повторного PATCH после 401 |
| AC-002 | В WKWebView вызваны prepare, confirm и updateEvent для полного цикла создания и редактирования. Go проверил конфликт до первой записи, сохранение результата и блокировку дублей после перезапуска. Проверен multipart для выбранного файла и отклонение симлинка. Нативный диалог выбора файла не автоматизирован |
| AC-003 | Сквозной WKWebView вызвал перенос и удаление, сервер увидел один DELETE. Go проверил получение карточки от организатора, перенос с потерянным ответом, материализацию и удаление одного вхождения либо вхождения с последующими. Для повторной отправки того же удаления возвращается подтверждённый результат |
| AC-004 | Журнал до отправки, сверка после записи, сброс кеша. Go-тест повторяет перенос после перезапуска и 503, число PUT не растёт. Для создания с потерянным ответом новый черновик после перезапуска получает состояние unknown, дополнительный POST не отправляется |

Прошли `npm run typecheck`, отдельная проверка TypeScript адаптера, сборки Vite и Go, `go vet ./...`, `SMALL_WAILS_WEBVIEW_TEST=1 go test -race -count=1 -v ./...` и скрытый запуск собранного приложения с чистым профилем. Фоновый Playwright Electron прошёл 10 из 10 сценариев из `event-rsvp`, `calendar-create`, `manual-meeting-conflicts` и `series-deletion`.

Переименование и перенос через диалог области серии сохраняют статус неподтверждённого серверного контракта из Electron. Перенос с собственным ID использует отдельный ранее согласованный путь. Для сравнения оболочек использованы синтетические сценарии. Запись на рабочем API Small и интерактивный системный диалог вложений не проверялись.
