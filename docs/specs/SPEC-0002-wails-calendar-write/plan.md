# Порядок переноса

Начать с ответа на приглашение. Затем перенести создание встречи с черновиком и проверкой конфликтов, редактирование и перенос, удаление и операции с сериями. Для каждого среза сравнить запросы, результат в UI и поведение при отказах. Для отката на период миграции использовать Electron и сверять уже подтверждённые сервером записи.
