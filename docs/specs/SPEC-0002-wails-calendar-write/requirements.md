# Запись встреч в Wails

Перенести календарные записи на Go, сохранив React UI и действующие серверные контракты. Сравнение выполняется на синтетическом API.

- AC-001. Из карточки можно принять и отклонить приглашение. Проверяются аккаунт и участие, PATCH после 401 не повторяется.
- AC-002. Для создания и редактирования сохраняются проверка конфликтов, права, подтверждения и защита от дублей.
- AC-003. Перенос и удаление сохраняют правила обычных и повторяющихся встреч, включая выбор экземпляра или серии.
- AC-004. После записи кеш и экран согласованы. Неопределённый исход проверяется чтением до повторной записи, где это предусмотрено исходным контрактом.
