# Ревью

Независимое ревью выполнено на рабочей копии от `776bdd5`. Проверены границы записи, время и права, обработка потерянного ответа и повторное создание. По замечаниям добавлены проверка локального дня и рабочих окон, отказ при неполных карточках, новая запись журнала после подтверждённой отмены прежней встречи и открытие вложения без следования симлинкам. Создание без переговорной использует исходный контракт Small с отсутствующим `calendar_ids`.

Результаты проверки и ограничения приведены в [протоколе](verification.md).
