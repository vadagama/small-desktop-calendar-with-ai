# Форматы профиля

Приложение принимает явные каталоги источника и назначения до запуска WebView. Импорт ограничен файлами приложения и выполняет атомарную публикацию нового каталога рядом с временным. Хранилища ассистента продолжают читать прежние данные. Сессия Electron из локального AES-GCM контейнера преобразуется в контейнер Wails. Совместимый адаптер читает старый календарный кеш только для подтверждённого аккаунта и учитывает прежний срок годности. Журналы сохраняют исходные записи и учитываются перед календарными записями Wails.

Исходный Electron хранит черновики, активный чат, раскладку Dockview и геометрию окна в памяти или создаёт их при запуске. Chromium хранит служебные данные платформы. В правила импорта входят только именованные файлы приложения.

| Данные Electron | Перенос в Wails |
| --- | --- |
| `agent-settings.json`, `assistant-templates/`, `topic-rules.json` | Прежние настройки, пользовательские шаблоны и правила тем |
| `llm-profiles.json`, `local-vault/master.key`, `local-vault/secrets/` | Прежняя схема. Секреты и память остаются зашифрованными |
| `participant-memory/` | Прежняя схема, включая импорт устаревших записей при первом чтении памяти |
| `reminders.json` | Прежние настройки и журнал доставки с совместимыми ключами |
| `voice/source.json`, `voice/ggml-large-v3-turbo.bin[.part]` | Настройка источника, установленная модель или частичная загрузка. Рантайм проверяет модель перед использованием. Идентификаторы устройств зависят от WebView |
| Запись `small-auth-session-v1` | Сессия и CSRF в зашифрованном файле Wails. Первый запуск подтверждает аккаунт через Small. Локальная запись с паролем старого формата остаётся в исходном профиле |
| `event-cache/`, `event-cache.dirty` | Формат Electron сохранён. Готовые ответы читаются при недоступности календаря, только по подтверждённому аккаунту. Каталоги действуют до суток, события до семи дней. Отказ в доступе и запись события инвалидируют затронутый кеш |
| `meeting-operations/`, `event-mutations/`, `series-mutations/` | Исходные записи и защита от повторов. Сверка неопределённого исхода выполняется в Electron до повторного импорта |
