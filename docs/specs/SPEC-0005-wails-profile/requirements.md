# Перенос профиля Electron в Wails

| Критерий | Проверяемое поведение |
| --- | --- |
| AC-001 | Явная команда с двумя путями копирует профиль из закрытого Electron в новый каталог Wails. Исходник сохраняется. При сбое копирования каталог назначения отсутствует. После публикации команда отдельно сообщает о сбое синхронизации родительского каталога. Повтор не перезаписывает профиль |
| AC-002 | Сохраняются настройки, правила тем, профили и ключи моделей, память, группы, форматы встреч, память участников, настройки и журнал напоминаний, выбранный источник звука и загруженная модель. Значения профиля изолированы от других аккаунтов |
| AC-003 | Сохранённая сессия перепаковывается без пароля. Wails проверяет её через Small перед использованием аккаунта. Истёкшая сессия сохраняет подсказку входа. Кеш доступен после подтверждения аккаунта с прежним временем загрузки и ограничениями срока |
| AC-004 | Журналы сохраняются. При совпадении с незавершённой операцией Electron Wails исключает повтор записи и предлагает завершить сверку в Electron. Временные файлы, черновики, активная переписка и расположение окон следуют прежнему поведению при перезапуске |
| AC-005 | Репетиция на синтетических данных проверяет запуск Wails после импорта и возврат к исходному профилю. Чистый запуск Wails по умолчанию остаётся чистым. Сборка или проверка импорта не переключает реальный профиль |

Выходные материалы для выпуска включают результаты проверок, оставшиеся условия приёмки UI и команды импорта и отката. Публикация запускается отдельно.
