# Независимое ревью импорта

Проверена рабочая копия от `776bdd54f9880bd51dbcf89c309711b21b139379` с локальными изменениями.

| Обнаруженный риск | Исправление и проверка |
| --- | --- |
| Старый кеш мог вернуться после подтверждённого отказа в доступе | Отзыв сохранённого каталога и сброс доступности импортированных событий. Сквозной тест проверяет последовательность 403 и 503 |
| Повтор записи мог обойти журнал из-за различий сериализации | Хеш ключа использует сериализацию, совместимую с JSON.stringify. Тест использует журналы, созданные кодом Electron, включая идентификатор со спецсимволами |
| На регистронезависимом диске целевой каталог мог оказаться внутри исходного | Сравниваются файловые идентификаторы исходника и предков назначения. Есть отдельный тест |
| Неполная или большая запись сессии могла дать непригодный профиль | Проверяются обязательные поля, формат и общий предел записи и чтения. Сессия перечитывается до публикации каталога |
| Исходный журнал не меняется при сверке в другой программе | Руководство фиксирует повторный импорт в новый каталог после сверки в Electron и границу отката после новых записей |

Повторное ревью устранило блокирующие замечания в проверенном объёме импорта. В аварийном случае отказа файловой системы Wails блокирует чтение затронутого кеша в текущем процессе. На исправном хранилище отзыв каталога и маркер инвалидирования событий синхронизируются с диском.
