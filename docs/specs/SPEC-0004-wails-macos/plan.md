# Порядок переноса

Сравнить зависимости Electron и Wails и закрепить существующие React-контракты. Перенести планировщик и жизненный цикл окна, подключить системные уведомления и общий контроллер Whisper. Собрать локальную arm64 версию и прогнать прежние сценарии в Electron и новые сценарии в скрытом WKWebView.

Воспроизводимая локальная упаковка использует `npm run package:wails:mac`. Для стабильного пакета команда принимает `-- --release --notes <file>` и использует Developer ID, нотариальный профиль, Apple Team ID и внешний файл закрытого ключа Ed25519. В приложение попадает только открытый ключ. Публикация выполняется отдельной командой выпуска. Перед включением канала проверить установку между двумя подписанными версиями в отдельном профиле macOS.
