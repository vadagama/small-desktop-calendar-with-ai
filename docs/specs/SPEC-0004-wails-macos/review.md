# Ревью

Два независимых ревью рассмотрели рабочую копию от `776bdd5`. Планировщик фиксирует доставку каждой встречи непосредственно перед отправкой, освобождает блокировку данных перед нативным вызовом, перепроверяет поколение сессии и удаляет устаревшее уведомление. Неполный календарь очищает карточки и показывает предупреждение. Быстрое закрытие окна отменяет запись по ID её сессии. Делегат WebKit проверяет локальный главный кадр и снимает разрешение при навигации.

Проверка обновления передаёт текстовое требование `codesign -R` с префиксом `=`. Упаковка записывает digest в base64 и подписывает его Ed25519. Локальная проверка подтвердила подготовку корректного пакета и отказ при повреждённой подписи. Временная копия удаляется при выходе до передачи помощнику Wails.
