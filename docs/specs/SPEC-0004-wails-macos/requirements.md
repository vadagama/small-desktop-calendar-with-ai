# Интеграции macOS в Wails

| Критерий | Проверяемое поведение |
| --- | --- |
| AC-001 | Напоминания читают свежий «Мой календарь», работают после закрытия окна и после сна, соблюдают настройки 0–60 минут и сохраняют журнал доставки по прежней схеме. Ссылку перепроверяет Go после действия пользователя |
| AC-002 | Нативные уведомления поддерживают системное действие и повторное открытие окна. Диагностика отличает отправку запроса от появления в Центре уведомлений |
| AC-003 | Голос работает через нынешние React-компоненты, локальный Whisper и проверенную модель. Получение звука требует активной сессии главного локального фрейма |
| AC-004 | Воспроизводимый arm64 DMG открывается с чистым профилем. Путь стабильного обновления отделён от Electron, загружает и проверяет пакет и запрашивает подтверждение перед перезапуском |

Контракты для сравнения описаны в [напоминаниях](../../implementation/t11-reminders.md), [нативной доставке](../../implementation/macos-notification-delivery.md), [голосовом вводе](../../implementation/voice-input.md) и [обновлениях](../../implementation/auto-updates.md).
