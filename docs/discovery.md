# Discovery: Small Desktop Calendar

Дата: 28 октября 2026 года. Цели и границы ниже подтверждены пользователем
в discovery-диалоге. Детали реализации остаются в [спецификации](spec-v1.md).

## Зачем нужен продукт

Сократить ручную координацию встреч в Small и дать понятную картину того,
на что уходит запланированное время. Больше всего времени занимает поиск
общего свободного слота, особенно для больших групп участников.

Клиент предназначен сразу для нескольких сотрудников с одинаковым функционалом.
Каждый работает под своим аккаунтом и в пределах своих прав в Small Team.
Первым пользователем для проверки сценариев будет инициатор проекта.

## Подтверждённые сценарии

1. Найти общий слот для нескольких сотрудников или целой команды.
2. Создать встречу из запроса естественным языком: участники, время,
   содержательная адженда и необходимые ссылки, включая онлайн-конференцию.
3. Изменить, перенести или отменить встречу по существующим правилам ассистента.
4. Получить аналитику количества и запланированной длительности встреч
   за период с разбивкой по темам и командам.
5. Вовремя подключиться к встрече из меню macOS или уведомления.

Первый подтверждённый пример аналитического запроса:
«Сколько часов за месяц у меня ушло на регулярные встречи, по каким темам
и с какими командами?» Календарные данные показывают запланированное время,
а не подтверждённое присутствие на встрече.

## Подтверждённый опыт использования

- В главном окне слева календарь с настройкой представлений, справа развитый
  AI-ассистент. Конкретные представления ещё предстоит выбрать.
- Авторизация встроена в приложение. У каждого сотрудника свой аккаунт;
  не нужны скрипты, ручное копирование токенов или прописанный в коде пользователь.
- Сессия хранится в Связке ключей macOS и обновляется автоматически.
  Потребность в повторном входе объясняется в интерфейсе.
- Закрытие окна оставляет приложение работающим в строке меню macOS.
  Полный выход — отдельное действие.
- Пользователь настраивает, за сколько минут до встречи придёт уведомление.
- В карточке встречи в меню достаточно названия, начала и окончания,
  организатора и ссылки для подключения. Её задача — помочь вовремя подключиться.
- Ассистент должен работать быстро. По просьбе пользователя числовые показатели
  задержки на этом этапе не задаются.

## Направление технологий

Пользователь предпочитает TypeScript-харнес, который проще реализовать
и поддерживать, с поддержкой рассматриваемых GLM / DeepSeek Flash.
Точные идентификаторы моделей и API-провайдеры не определены.
Electron, Tauri/Pake, Pi Durable и Hermes не являются принятыми решениями.

## Основа в существующем проекте

С разрешения пользователя изучены локальные материалы проекта `Work tasks`:
`INTEGRATIONS.md`, календарные записи `HISTORY.md`, скрипты `calendar_api.py`
и `team_auth.py`, а также связанный skill `small-team-meeting-create` и его
справочник API. Они служат источником сценариев и технических гипотез,
а не готовой реализацией нового клиента. Персональные данные, секреты,
черновики и реальные payload встреч сюда не переносятся.

| Наблюдение | Что подтверждено и что требует проверки |
| --- | --- |
| API календаря | По коду и истории есть чтение, поиск слотов, создание и отмена; текущий сервер в рамках discovery повторно не проверялся. |
| Авторизация | Python-код хранит сессию в Keychain и обновляет токен; привязка аккаунта в прототипе персональная. |
| Поиск сотрудников | Endpoint каталога и полнота состава команд ещё не подтверждены. |
| Повторяемость | Сведения есть в восстановленном контракте, но текущий клиент блокирует операции с сериями. |
| Конференции | Правила формируют отдельную ссылку meet.small.kz; генерация адреса не доказывает резервирование комнаты. |
| Аналитика и macOS | Готовой аналитики встреч и реализации нативных уведомлений в изученной интеграции не найдено. |

В материалах встречаются устаревшие отметки о ненастроенной авторизации;
более поздние записи истории описывают успешные операции. Это исторические
свидетельства, а не гарантия текущей работоспособности API.

## Границы первой версии

Включены календарь, управление встречами, аналитика встреч, вход и интеграция
с macOS. Управление задачами Linear и остальные функции `Work tasks`
в первую версию не входят. Фактическую посещаемость не выводим из календаря.
Другие ОС и дополнительные интеграции не являются согласованными обязательствами.

## Признак успеха

Пользователь проходит путь от «собери людей» до подтверждённой встречи,
видит результат в календаре и получает напоминание для подключения.
Отдельно он может получить проверяемую сводку запланированных встреч за период.

Следующая стадия — ревью продуктовой спецификации и проверка технических
неизвестных перед выбором стека и планированием реализации.
