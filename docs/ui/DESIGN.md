# Интерфейс Ordo

Целевой интерфейс находится в `src/renderer/`. Его точка сборки — [конфигурация Wails/Vite](../../desktop-wails/vite.config.ts). Используйте существующие компоненты React, shadcn и Dockview. Для размеров текста и плотности применяйте [типографику Ordo](../design/typography.md). Проверяйте итоговые размеры в WKWebView.

Браузерный [прототип](../../prototype/) имеет собственный [дизайн](../../DESIGN.md) и сборку. Проверяйте перенос решений в основной интерфейс по спецификации функции.
