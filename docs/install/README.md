# Страница установки

Статическая инструкция для GitHub Pages. `index.html` + `style.css` + `assets/`;
без сборки, аналитики, внешних шрифтов и форм сбора учётных данных.

Контракт: восемь последовательных шагов, включая настройку LLM/Voice и диктовку, основное действие — скачать DMG.
Навигация слева на desktop, горизонтальная на узком экране; картинки открываются
в полном размере. Макеты авторизации — не интерактивные формы и явно подписаны.
Введение содержит синтетический скриншот календаря из Electron E2E и описание
возможностей. Шаги установки иллюстрируют три снимка DMG и системных диалогов.
Токены типографики повторяют значения общего UI; сайт развёртывается независимо
от приложения, поэтому не импортирует полный CSS календаря.

Проверка: `python3 -m http.server 4180 --bind 127.0.0.1 --directory docs/install`.
Проверить widths 320/768/1024/1440, якоря, details, клавиатуру, загрузку изображений.
При обновлении релиза менять прямую ссылку DMG, дату, размер и параметры профиля.
Публикация релиза: `.agents/skills/build-release/SKILL.md`.
По прямому поручению пользователя инструкция публикуется на GitHub Pages:
https://vadagama.github.io/small-desktop-calendar-with-ai/ . Источник публикации —
ветка `codex/install-pages`, корень. Публикуются только файлы этой папки.
В Pages-артефакт включать только содержимое этой папки. Не публиковать остальные
документы и данные репозитория. После деплоя проверить публичную страницу,
Changelog и скачивание DMG именно нового GitHub Release.

В 0.2.0-rc.7 добавлены подтверждаемое добавление участников через ассистента,
редактирование составов до 100 сотрудников, сохранение ответов на приглашения
и обновления календаря без перекрытия открытых диалогов.
