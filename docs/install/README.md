# Страница установки

Статическая инструкция для GitHub Pages. `index.html` + `style.css` + `assets/`;
без сборки, аналитики, внешних шрифтов и форм сбора учётных данных.

Контракт: шесть последовательных шагов, основное действие — скачать DMG.
Навигация слева на desktop, горизонтальная на узком экране; картинки открываются
в полном размере. Макеты авторизации — не интерактивные формы и явно подписаны.
Использованы три предоставленных скриншота без персональных данных; скриншоты
с именем пользователя и календарными событиями не публикуются.
Токены типографики повторяют значения общего UI; сайт развёртывается независимо
от приложения, поэтому не импортирует полный CSS календаря.

Проверка: `python3 -m http.server 4180 --bind 127.0.0.1 --directory docs/install`.
Проверить widths 320/768/1024/1440, якоря, details, клавиатуру, загрузку изображений.
При обновлении релиза менять прямую ссылку DMG, дату, размер и параметры профиля.
Публикация: содержимое этой папки в корне отдельной ветки `codex/install-pages`,
GitHub Pages → Deploy from a branch → эта ветка → `/`.
Не публиковать остальные документы и данные репозитория.
