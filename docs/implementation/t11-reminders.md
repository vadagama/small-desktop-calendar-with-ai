# T11 — Напоминания и подключение

Реализовано 29 октября 2026 года. Пользователь подтвердил диапазон 0–60 минут
и правило пробуждения: после чтения календаря напоминать об ещё идущих встречах,
завершённые пропускать. По умолчанию включено, за 5 минут.

## Поведение

Кнопка колокольчика открывает настройки и текущие напоминания. Параметры
сохраняются локально; источник — «Мой календарь», независимо от фильтров окна.
Main опрашивает текущий и следующий день Asia/Almaty каждые 30 секунд.
Задержка доставки относительно выбранного времени — до интервала опроса плюс сеть.
Открытие окна напоминаний также обновляет данные. После сна устаревший запрос
инвалидируется и календарь читается заново. Без сети или при неполных данных
напоминания не доставляются из старого снимка.

Нативное уведомление содержит название, интервал, часовой пояс и организатора.
Для корректной HTTP(S)-ссылки доступно действие «Подключиться». Нажатие на
уведомление открывает приложение. Внутри приложения есть те же сведения и
кнопка подключения; отсутствие ссылки обозначено явно. Перед открытием main
повторно читает событие, проверяет аккаунт, время, актуальность и схему URL.
Сам URL конференции не запрашивается: он передаётся внешнему браузеру только
по действию пользователя. Произвольные протоколы и URL с credentials запрещены.

Закрытие окна на macOS сохраняет планировщик; Cmd+Q полностью завершает процесс.
Повторный запуск того же профиля открывает существующий экземпляр. Автозапуск
не включён. После запуска применяется такое же правило актуальных встреч,
как после пробуждения; доставка при выключенном приложении не обещается.

## Дедупликация и данные

Идентификатор — SHA-256 от аккаунта и ключа события, без времени для конкретного
ID. Перенос до доставки меняет время; перенос после доставки обновляет карточку,
но не повторяет системное уведомление. Отмена и завершение убирают карточку и
закрывают нативное уведомление при следующей успешной синхронизации.
Смена аккаунта сразу инвалидирует текущие запросы и очищает уведомления.

`reminders.json` содержит настройки и хеши отправленных напоминаний с временем
окончания, без названий, участников и ссылок. Запись сериализована, файл заменяется
атомарно, права 0600. Записи удаляются спустя 30 дней после последнего известного
окончания. Claim фиксируется до вызова ОС: при аварии в этот короткий промежуток
баннер может быть пропущен, но не повторён; карточка восстанавливается чтением.
Изменение настройки минут не создаёт повторную доставку уже отмеченного события.

## Проверки

- Unit: граница пяти минут; параллельные опросы; перезапуск; перенос до/после
  доставки; отмена; завершение; пробуждение; неполные данные; смена аккаунта
  во время запроса; диапазон и сохранение настроек; URL и повторное чтение.
- Electron: сохранение настройки, закрытие всех окон, пробуждение и доставка
  с закрытым окном, повторное открытие приложения, отказ нативной доставки,
  отсутствие дублей и очистка после выхода. API и Notification заменены
  синтетическими границами; тесты не создают реальные встречи.
- Пройдены typecheck, unit suite, desktop build и Electron suite; точные итоги
  записаны в PR.

## Открытые ограничения

Реальная доставка в системный Центр уведомлений, разрешения и Focus ещё требуют
проверки подписанной macOS-сборки. `Notification.isSupported()` не подтверждает
разрешение пользователя; `failed` показывает предупреждение и сохраняет карточку
в приложении. Нет заявления об успешной системной доставке только по вызову show.
См. [Electron Notification](https://www.electronjs.org/docs/latest/api/notification)
и [powerMonitor](https://www.electronjs.org/docs/latest/api/power-monitor).

Для виртуальных вхождений используется существующий серверный ключ календаря.
Стабильность этого ключа при переносе/материализации серии не подтверждена;
отсутствие дублей между виртуальным и материализованным представлениями требует
контракта T13. Для разового события стабильный ID проверен синтетически.
Смена серверного ID и перенос после удаления старой записи журнала могут привести
к новому напоминанию. Статусы участия берутся из доступности события в «Моём
календаре»: отдельный серверный контракт declined/cancelled пока не добавлен.
