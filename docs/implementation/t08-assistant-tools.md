# T08 — Подбор времени из AI-чата

После входа в Small и выбора реального LLM-профиля чат предоставляет
`searchPeople` и `findSlots`. Синтетический профиль сохраняет прежнюю проверку
сложения. Без Small-сессии календарные инструменты не предоставляются.

## Сценарий

1. Попросите найти сотрудника по имени. Карточка показывает всех людей страницы,
   их должности, ID и номер следующей страницы. Однофамильцы не объединяются.
2. Отправьте отдельное сообщение вида
   `Участники: [ID1, ID2]. Дата 2026-11-02, 30 минут`, заменив ID результатами
   поиска. Каждый запрос обрабатывается отдельно: история чата модели не передаётся.
3. Карточка показывает дату, длительность, весь состав и проверенные интервалы
   в `Asia/Almaty`, либо ошибку или отсутствие вариантов. Встречи не создаются.

Явный список нужен для проверки состава вне модели. Main сравнивает множества
и количество участников: нельзя добавить человека, исключить часть списка,
передать повтор или неоднозначно указать несколько списков. Распознавание людей
по свободному тексту и удобный выбор непосредственно в карточке остаются развитием
интерфейса. Указанные вручную ID не доказывают полноту команды по подразделению.
Дата и длительность извлекаются моделью; их нужно сверить в карточке результата.

## Границы

Main фиксирует аккаунт на начало запроса. Worker получает только результаты
двух операций, без Small-токенов, cookies и выбора URL/аккаунта. Вход проверяется
схемами повторно в main, доступ к сессии и смена аккаунта — существующим сервисом.
Результаты поиска сотрудников и слоты передаются выбранному LLM-профилю.
Имена из API считаются данными, а не инструкциями.

SDK ограничен шестью шагами, main — двенадцатью вызовами и временем существующего
задания (30 секунд). Отмена, навигация, выход или смена профиля прекращают выдачу
результатов; запоздалый ответ игнорируется. Уже начатый HTTP-запрос чтения может
завершиться в фоне. Ошибки неизвестных исключений не раскрывают payload сервера.

  preload и UI; сетевые границы заменены синтетическими серверами.
- Проверены однофамильцы, конфликтующий слот, отсутствие явного состава,

  Снимок 900×640 просмотрен после завершения перерасчёта компоновки.

Упаковка и подпись приложения для этого среза отдельно не проверялись.
