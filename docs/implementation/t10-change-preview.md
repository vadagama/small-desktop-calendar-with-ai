# T10 — Предпросмотр изменения разовой встречи

В карточке выбранного события доступны подготовка нового названия и предпросмотр
отмены. Они заново читают событие из Small и показывают предложение с актуальными
названием, временем, составом, описанием и местом. Редактирование поля убирает
предыдущий предпросмотр. Данные предложения не считаются подтверждением записи.
Кнопки применения нет; реальные встречи и приглашения не меняются.

## Проверки границ

Main принимает только accountId, конкретный eventId и действие rename/cancel.
Сессия Small проверяет аккаунт до чтения и после него. Ответ обязан содержать
совпадающий ID, creator_id, явный is_recurring, участников и временной интервал.
Отсутствующие сведения не трактуются как разрешение. Только совпадение creator_id
с текущим аккаунтом разрешает подготовку; это консервативная клиентская проверка,
а не полная модель серверных прав. Административные исключения не предполагаются.

Серии, original_event_id, recurrence_rule и виртуальные вхождения блокируются.
Для них не вызывается from-template. Предпросмотр использует только GET;
новых PUT/DELETE/POST-маршрутов транспорт не разрешает. Ответы ошибок не открывают
способ отправить запись. Устаревшие ответы после закрытия формы отбрасываются.

## Основания и ограничения контракта

29 октября 2026 повторно загружен публичный клиент https://team.small.kz/calendar:
`index-Dwj9jIUp.js`, SHA256
`048bc4eb0b16ac72976f2f51760a54e92e1fa4456ae318f0d5952e3b58f5f355`.
Хеш совпал с исследованием T09. Код карточки сопоставляет creator_id с текущим
ID. Клиент editEvent использует PUT с force, диалог удаления разового события
использует DELETE. POST cancel с reason относится к текущему вхождению серии.
Эти пути нельзя считать взаимозаменяемыми по названию.

До применения изменений нужно проверить серверную семантику PUT и сохранение
неизменённых полей, механизм защиты от конкурентной правки и результат удаления.
Обычный 404 после DELETE сам по себе не доказывает успешную отмену: может измениться
доступ. Нужны повторная проверка прав/версии, явное подтверждение, журнал намерения
и сверка неизвестного результата без повтора записи. Они относятся к следующему
срезу T10. Перенос времени, смена состава и AI-инструменты изменения пока не добавлены.
