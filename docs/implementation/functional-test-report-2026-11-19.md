# Проверка существующего функционала — 19 ноября 2026

Проверена текущая рабочая копия, включая уже существовавшие незакоммиченные
изменения. Автоматические записи идут только в синтетический Small API.
Браузерные тесты headless, Electron — со скрытыми окнами и временными профилями.

## Исправления

- Добавлен инструмент ассистента для добавления участников разовой встречи
  организатора. Карточка требует подтверждения, сохраняет существующий состав
  и остальные поля, использует проверки прав и конфликтов редактора.
- Приглашённый участник распознаётся по составу встречи даже без `is_informed`.
  Контрол «Придёте? Да / Нет» появляется в карточке; отказ восстанавливается
  после повторного открытия, как и согласие.
- Тест создания из сетки учитывает явное подтверждение обеденного конфликта.

- `calendar-create.spec.ts`: ожидал создание в 13:00–14:15 без подтверждения

- `calendar.spec.ts` и `calendar-filters.spec.ts`: ожидают кнопку
  «Переговорные», отсутствующую в текущем `CalendarFilters.tsx`. Её отсутствие
  предшествует этой задаче. Тесты не отключены и интерфейс не восстановлен.
- `meeting-time.spec.ts`: timeout в полном прогоне; отдельный запуск прошёл.
  В итоговом полном прогоне также прошёл. Причина первоначального timeout не установлена.
- Реальный Whisper-тест пропущен штатным условием: не заданы
  `SMALL_VOICE_TEST_MODEL` и `SMALL_VOICE_TEST_WAV`.

Новые проверки RSVP сначала воспроизвели отсутствие контрола, затем прошли
на исправленной сборке. Проверены оба ответа, повторное открытие, 14px computed
font-size, отсутствие ошибок renderer и скрытое состояние окон.

Сквозной сценарий ассистента в итоговом прогоне прошёл: preview без записи,
явное подтверждение конфликта, сохранение старых участников и остальных полей.
Скриншоты: `test-results/desktop/assistant-participants-preview.png` и
`test-results/desktop/event-rsvp.png`.
