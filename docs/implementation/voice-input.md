# Локальный голосовой ввод

Реализация в Electron для macOS arm64. UI-прототип в `prototype/` остаётся
демонстрационным; настоящий захват и Whisper подключены в `src/renderer/` и
`src/main/voice/`.

## Использование

1. Открыть «Настройки модели» → вкладка **Voice**. Вкладка **LLM** содержит настройки языковых моделей.
2. Скачать Whisper large-v3-turbo (1,62 GB). Интерфейс показывает проценты,
   объём, скорость и приблизительное оставшееся время; есть пауза, продолжение
   и отмена. После проверки появляется чип «Модель готова» и кнопка удаления.
3. Выбрать источник звука; при необходимости проверить уровень микрофона.
   macOS запрашивает разрешение при первом обращении.
4. Нажать микрофон рядом с отправкой сообщения. Остановить запись кнопкой
   с квадратом; текст вставляется на место выделения или курсора.
   Отредактировать и отправить самостоятельно. Escape отменяет запись
   или распознавание. Максимальная запись — 120 секунд.

Модель не входит в пакет приложения. После установки сеть для распознавания
не нужна. Текст не обрезается при превышении лимита сообщения: пользователь
должен сократить его до 2000 символов перед отправкой.

## Устройство и границы доверия

- Движок: [whisper.cpp v1.8.3](https://github.com/ggml-org/whisper.cpp/tree/v1.8.3),
  закреплённый commit `2eeeba56e9edd762b4b38467bab96c2517163158`.
  Статическая сборка с Metal; отдельный процесс с фиксированными аргументами,
  без shell и без передачи произвольных путей из renderer.
- Multilingual large-v3-turbo, язык `ru`; закреплённые ревизия, размер и SHA-256
  находятся в `src/main/voice/model.ts`. Это выбор баланса скорости и качества,
  а не результат сравнительного бенчмарка всех моделей русского языка.
- Загрузка через HTTPS только с Hugging Face и его CDN; Range проверяется,
  `.part` сохраняется для продолжения. SHA-256 и пробная загрузка движком
  предшествуют атомарному переименованию в установленную модель.
- AudioWorklet собирает моно PCM; на границе IPC проверяются структура,
  владелец активной сессии, длительность, конечность и диапазон отсчётов.
  Одновременно разрешена одна запись/проверка/транскрипция.
- Доступ к микрофону ограничен доверенным главным frame локального приложения
  и активной сессией. Камера и удалённое содержимое календаря доступа не получают.
- WAV и результат создаются в закрытой временной папке и удаляются после
  завершения/ошибки/отмены; остатки после аварийного закрытия очищаются при старте.
  Записи и распознанный текст не пишутся в диагностические логи.
- Процесс распознавания ограничен 60 секундами; отмена завершает его.
  Отключение устройства требует повторного выбора, без скрытого переключения.

## Сборка

Требуются Xcode Command Line Tools, Git и CMake. `CMAKE` может содержать
абсолютный путь к исполняемому файлу CMake.

```sh
npm run voice:build
npm run build:desktop
npm run package:mac:local
```

`voice:build` проверяет commit исходников и помещает бинарник, лицензию и версию
в игнорируемую Git папку `native/voice/`. Упаковка добавляет её в Resources
вне ASAR и задаёт `NSMicrophoneUsageDescription`. Веса, пользовательские профили
и аудиозаписи туда не включаются. Текущая упаковка ориентирована на arm64.
Локальная подпись предназначена для проверки на этом Mac, не для распространения.

## Проверки

`npm run typecheck`, `npm test`, `npm run build:desktop` и
`npm run test:desktop -- tests/desktop/voice.spec.ts`.

Полный тест настоящего Whisper требует внешних файлов модели и синтетической
русской WAV-записи (они не хранятся в репозитории):

```sh
SMALL_VOICE_TEST_MODEL=/absolute/path/ggml-large-v3-turbo.bin \
SMALL_VOICE_TEST_WAV=/absolute/path/synthetic-russian.wav \
npm run test:desktop -- tests/desktop/voice.spec.ts
```

Тест сохраняет sandbox: проверяет разрешение на fake device и подаёт синтетическую
речь через MediaStream в реальный AudioWorklet → IPC → whisper-cli. Системный
диалог разрешения заменён только внутри теста. Проверяются вставка в черновик,
отсутствие автоотправки, отмена, готовность модели и computed typography.
Отдельно проверено настоящее HTTP-докачивание последнего MiB модели с последующей
сверкой всей контрольной суммы и пробным запуском.

Ограничения проверки: реальный физический микрофон и диалог macOS требуют ручного
smoke-теста. Сравнительный корпус русской речи пока не измерен. Холодный отдельный
запуск с короткой синтетической фразой занял около 11 секунд на проверяемом Mac;
целевой порог 5 секунд из предложения не подтверждён. Модель загружается заново
для каждого запроса, что ограничивает скорость, но освобождает память после работы.
