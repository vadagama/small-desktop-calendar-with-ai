# Сверка доступности с прототипом

Первичная сверка до исправления источника; геометрия остаётся актуальной. Исправленная рабочая политика взята из backend, поэтому синтетический обед прототипа не переносится в production. [Актуальный снимок](availability/availability-fixed-result.png).

Скрытый Electron, одинаковые синтетические Анна/Иван/Мария, неделя 16–20 ноября 2026, длительность 60 минут, рабочее окно 09–18, контейнер 1000×808 CSS px, scrollLeft 512. Данные в тесте повторяют формулу occupancy последнего прототипа, сам прототип ради сравнения не изменён. Его временный Vite-сервер поднимается самим E2E.

| Проверка DOM        | Прототип / приложение      |
| ------------------- | -------------------------- |
| Колонка участников  | 184 / 184 px               |
| Строка сотрудника   | 44 / 44 px                 |
| Заголовок даты      | 34 / 34 px                 |
| Временная область   | 1536 / 1536 px, 64 px/час  |
| Заливка общего окна | rgb(223, 242, 252) / та же |

Снимки просмотрены после теста: [приложение](availability/availability-comparison-app.png), [прототип](availability/availability-comparison-prototype.png). Сохранены белые панели, нейтральная навигация, голубые свободные интервалы и контур общих окон. В рабочем экране дополнительно видны требуемые фильтры день/неделя и временное окно; picker повторно использует форму события. Шрифты взяты из общих токенов, а не из Retina-размеров снимка. В Electron assertions: заголовок 14 px, имя 13 px.

Проверены панели шириной [320](availability/availability-320.png), [768](availability/availability-768.png), [1024](availability/availability-1024.png), [1440](availability/availability-1440.png) CSS px внутри desktop workspace. Это проверки ширины панели, не обещание мобильной версии всего desktop-приложения. В составе 20 сотрудников, 5/7 дней, длинные имена. Grid сохраняет внутреннюю прокрутку, имена закреплены при переходе к 24, строка/масштаб не сжимаются. Picker ограничен по высоте 140 px и прокручивается, поэтому не вытесняет сетку.

Состояния: [штатный результат](availability/availability-analysis.png), [поиск](availability/availability-search.png), [выбор](availability/availability-selection.png), [unknown](availability/availability-partial.png), [ошибка](availability/availability-error.png). Загрузка и ошибка не разрешают выбирать неподтверждённые интервалы. При ошибке обновления старый снимок явно помечается неактуальным, retry восстанавливает выбор.

Это проверка геометрии, данных, шрифтов и просмотр снимков; пиксельная идентичность внешней оболочки приложения и автономного прототипа не заявляется. Снимки полностью синтетические.
