# Исправление Electron E2E для PR #59

В CI после исправления CSS-бюджета оставались три сбоя тестов.
Изменения ограничены тестами; интерфейс и бизнес-логика не меняются.

- `availability-analysis`: исходное окно зависело от экрана runner. Заголовок
  имеет 16 CSS px на широком экране и 14 CSS px при ширине до 1150 px.
  Тест задаёт 1440×960 и отдельно проверяет 1000×800, затем возвращает широкий вид.
- `calendar-filters`: вместо отсутствующей вкладки «Переговорные» проверяется
  сохранение фильтров при переходе в «Свободные слоты» и обратно.
- `calendar`: узкая боковая панель проверяется по доступным личным фильтрам.
  Публичные календари проверяются через настоящий preload/main IPC:
  успешные данные, частичный результат с 403/503/невалидной записью,
  отказ без данных и подтверждённый пустой календарь. Чтение переговорных
  не должно заменять выбранный личный календарь на экране.

Изолированная рабочая копия без незакоммиченных пользовательских изменений;
Electron запускается со скрытыми окнами и отдельными временными профилями.

- До исправления воспроизведены оба сбоя вкладки; ошибка адаптивного шрифта
  подтверждена логом CI. После исправления все три целевых теста прошли.
- Полный Electron E2E: 61 passed, 1 failed, 1 skipped. Единственный сбой —
  Voice из-за отсутствия нативного runtime в новой рабочей копии.

  имеющегося runtime 1.8.3 / `2eeeba56e9edd762b4b38467bab96c2517163158`
  повторный Voice E2E: 1 passed, 1 skipped. Runtime не включён в коммит.
- Реальное распознавание штатно пропущено без `SMALL_VOICE_TEST_MODEL`
  и `SMALL_VOICE_TEST_WAV`.
- Unit: 580 passed; typecheck, format:check, build:desktop и check:size прошли.
