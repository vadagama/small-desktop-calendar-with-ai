# T01 — безопасный SDK-loop

Реализован и проверен 28 октября 2026 года на Node.js 22.23.2.

## Граница среза

`src/agent/runtime.ts` экспортирует `streamSyntheticTurn(model, options)`.
Нужны явный экземпляр модели, `prompt` и необязательный `abortSignal`.
Строковый model ID не принимается: SDK Gateway не выбирается неявно.
Функция возвращает стандартный SDK stream result, включая `fullStream`.
Уже отменённый запрос отклоняется с причиной отмены до обращения к модели.
Отмена активного потока даёт событие `abort`; ошибка модели — `error`.
Потребитель должен читать поток и различать эти состояния.

Единственный инструмент `addNumbers` принимает два целых числа от −1 000 000
до 1 000 000 включительно и возвращает `{ sum }`. Лишние поля, неверные типы
и некорректный JSON отклоняются; успешный результат инструмента не появляется.
Цикл ограничен тремя шагами модели, автоматические сетевые повторы отключены.
Это ограничение шагов не заменяет будущие timeout и пользовательскую отмену.

В тестах используется `MockLanguageModelV4` на LLM-границе; валидация,
выполнение инструмента, следующий шаг модели и поток событий проходят через
настоящий `ToolLoopAgent`. HTTP `fetch` в тестах заменён запретом сетевых запросов.
Переданная реальная модель может обращаться к сети: само ядро не является
сетевой песочницей. Credentials и создание provider относятся к T04.

## Воспроизведение

Из корня репозитория на Node.js ≥22.12.0:

```sh
npm ci
npm test
npm run typecheck
npm run build
npm run format:check
node --test --test-name-pattern 'streams a validated tool result' dist/tests/agent/runtime.test.js
```

Все команды проверки прошли. Первичная установка выполнена через
`npm install --ignore-scripts`, повторная чистая установка — через
`npm ci --ignore-scripts`; после неё все 12 тестов прошли повторно.
22 пакета проверены, найдено 0 уязвимостей.
Версии фиксируются в `package.json` и `package-lock.json`:
`ai` 7.0.155, `@ai-sdk/openai-compatible` 3.0.80, `zod` 4.6.7.
SDK и provider требуют Node ≥22; минимум проекта ≥22.12.0 совпадает с UI-стендом.
Отдельного линтера в этом срезе нет; `format:check` проверяет Prettier.

12 тестов проверяют результат инструмента и его передачу следующему шагу
модели, текстовые части потока, шесть ошибочных входов, неизвестный инструмент,
лимит шагов, активную и предварительную отмену, ошибку provider без повторов.
В тесте ошибки SDK выводит ожидаемое `synthetic provider failure` в диагностику;
сам тест проходит. Скомпилированный успешный сценарий запущен без TS-loader.

Перед реализацией тест завершился ошибкой отсутствующего runtime-модуля.
При проверке качества временное удаление предварительной проверки AbortSignal
сломало соответствующий тест; исходный код восстановлен.

## Источники и ограничения

- [ToolLoopAgent](https://ai-sdk.dev/docs/reference/ai-sdk-core/tool-loop-agent):
  инструменты, ограничение цикла и stream.
- [Тестирование SDK](https://ai-sdk.dev/docs/ai-sdk-core/testing):
  `MockLanguageModelV4` и `simulateReadableStream`.
- Версии, engines и peer dependencies сверены с npm metadata перед установкой.

OpenAI-compatible provider зафиксирован для следующего подключения, но ещё
не создаётся и не проверялся с реальным endpoint. Small vLLM, Keychain,
desktop-упаковка и UI transport остаются непроверенными. T01 не меняет
демонстрационный UI и не выполняет календарные операции. Следующий срез T02
зависит от решения по ADR-002.
