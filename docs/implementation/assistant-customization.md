# Настройки AI-помощника

Кнопка «Настройки AI-помощника» (иконка искр в заголовке чата) открывает редактор пользовательских инструкций и календарных навыков. Изменения применяются после сохранения со следующего календарного запроса. Уже запущенный запрос использует свой снимок настроек.

## Файлы и хранение

- `src/agent/content/system.md` — технические инструкции, поставляемые с приложением; в интерфейсе доступны только для чтения.
- `src/agent/content/skills/people-search/SKILL.md` — поиск сотрудников.
- `src/agent/content/skills/availability/SKILL.md` — подбор общего времени.
- `src/agent/content/skills/meeting-draft/SKILL.md` — подготовка черновика.
- `agent-settings.json` в Electron `app.getPath("userData")` — пользовательский текст, Markdown навыков и состояния включения. Файл записывается атомарно, отдельно от приложения. Обновление приложения его не заменяет.

Идентификаторы и назначения трёх навыков фиксированы. Пользователь редактирует Markdown и включает или отключает сценарии; импорт новых навыков и выполнение скриптов не поддерживаются. Метаданные внутри Markdown служат пояснением и не меняют набор инструментов.

Кнопка «Восстановить стандартные» сразу заменяет пользовательские настройки встроенными, включая очистку дополнительных инструкций. При повреждённом файле приложение показывает ошибку; автоматического удаления или скрытой замены файла нет. Восстановление доступно и в этом случае.

## Исполнение

Main-процесс загружает и проверяет конфигурацию, затем передаёт её utility-процессу. AI SDK получает технический промпт, пользовательские предпочтения и список включённых навыков. Инструмент `loadSkill` возвращает полный Markdown выбранного навыка по необходимости. Отключённый навык убирает соответствующий календарный инструмент из списка модели; исполнение дополнительно проверяется в utility- и main-процессах.

Пользовательские инструкции — предпочтения, а не разрешение на операции. Проверки прав, участников, интервала и создание по кнопке остаются в существующих сервисах. Никакого произвольного доступа к файловой системе, shell или новым API редактор не предоставляет. Ответы отображаются безопасным Markdown; HTML и внешние изображения не исполняются. Карточки заполняются результатами инструментов.

Для манеры общения доступен Mood: нейтральный, строгий, молодёжный, альфа и технарь. Он не меняет разрешения и условия подтверждения. Остальные предпочтения задаются свободным текстом. Отдельные поля рабочих часов, часового пояса и напоминаний не добавлены: подбор времени сейчас поддерживает Asia/Almaty, и произвольная настройка этих полей обещала бы поведение, которого сервис пока не реализует. Синтетическая локальная проверка арифметики не использует календарные настройки. Для календарного помощника нужны LLM-профиль и вход в Small.

Не храните ключи доступа в инструкциях: пользовательский текст и загруженные навыки отправляются выбранной модели. Файл настроек не является хранилищем секретов.

## Сборка и проверки

`electron.vite.config.ts` копирует Markdown в `out/main/content`. Общие модули main/worker размещаются рядом, чтобы относительные пути работали в собранном приложении и ASAR.

- `tests/agent/agent-settings.test.ts`: сохранение, повторное чтение, восстановление, валидация и повреждённые данные.
- `tests/agent/calendar-runtime.test.ts`: передача инструкций модели, загрузка навыка и блокировка отключённых инструментов.
- `tests/desktop/agent-settings.spec.ts`: редактирование в Electron, перезапуск, восстановление и клавиатурное закрытие.


## Шаблоны, справочники и миграция

`src/agent/content/references/*.md` загружаются инструментом `loadReference`.
Описание стилей — `src/agent/content/moods/*.md`. Шаблоны отображения —
`src/agent/content/templates/*.md`. Для настройки шаблонов без пересборки
поместите файлы с теми же именами в `assistant-templates/` внутри каталога
данных приложения и перезапустите приложение. Редактора шаблонов в UI нет.

Версия настроек 2 добавляет Mood. Стандартные тексты версии 1 заменяются новыми
только при полном совпадении с поставлявшимся текстом. Пользовательские правки,
дополнительные инструкции и отключённые навыки сохраняются. Если свой старый
скилл по-прежнему требует ID, обновите его вручную или восстановите стандартные.
Файлы `content/legacy` используются только для сравнения при миграции.

Поля шаблонов, память и ограничения описаны в [диалоге ассистента](assistant-dialogue.md).

## Пользовательские шаблоны запросов

На стартовом экране ассистента кнопка «Настроить шаблоны» открывает раздел
«Шаблоны запросов» в настройках AI-помощника. Можно добавить, изменить или
удалить до пяти текстов (до 2000 символов каждый). Сохранение сразу обновляет
быстрые запросы; нажатие отправляет текст как обычное сообщение пользователя.
Можно удалить все шаблоны. Несохранённые изменения не применяются.

Список хранится локально в настройках ассистента (`promptTemplates`). Старые
настройки получают исходные тексты из `suggestions.md`; явно сохранённый пустой
список остаётся пустым. Ограничения числа и длины проверяются в main, пустые
тексты отклоняются. Восстановление стандартных настроек восстанавливает также
шаблоны запросов. Шаблоны отображения карточек Markdown по-прежнему задаются
файлами вне приложения.
