# Сверка рабочего дерева и актуального main

Дата: 29 октября 2026 года. База: `8d7e0f2` (`origin/main`).

Исходная папка оставлена на `codex/t10-event-mutations`: 81 запись git status,
включая каталог tmp. Копия изменённых и новых файлов, исходный diff и машинная
сверка находятся в `tmp/integration-audit/` отдельного worktree integration-check.
Архив предназначен только для локального восстановления и не включается в коммит.

Из 80 файлов вне tmp: 34 совпадают с main побайтно, ещё 6 при трёхстороннем
слиянии не добавляют изменений к main. Уникальных новых путей нет. Остальные
40 файлов требуют разбора различий: несовпадение не означает, что надо заменить
main старым файлом. В старой копии отсутствуют напоминания, аналитика и UI серий,
которые уже присутствуют в main.

## Перенесённый срез: профиль модели

- Настройки показывают доступность ключа, маску с последними четырьмя символами
  (полный короткий ключ не раскрывается) и признак выбранного сохранённого профиля.
- Сохранение закрывает диалог; предупреждение об очистке прежнего ключа не скрывает
  признак текущего. Недоступность Keychain не блокирует открытие настроек.
- Повторное сохранение обновляет запись Keychain. Кэш чтения остаётся в main.
- Без профиля рабочий чат требует настройки модели. Синтетическая модель доступна
  только с явным тестовым флагом; сохранённый, но не выбранный профиль объясняется
  отдельно.
- Electron-сценарии настроек, чата, календарного ассистента, layout и аналитики
  приведены к закрытию диалога после сохранения. Размеры поля и заголовка проверяет
  сценарий profiles (14 и 18 CSS px).

До переноса реализации тесты профилей и Keychain падали; после переноса проходят.

## Остальные перенесённые изменения

- В выходной явно выбранный интервал проверяется по индивидуальной занятости.
  Неполное покрытие участников, конфликт, прошедшее время, другая дата или
  длительность не считаются свободой. Подбор в рабочий день по-прежнему использует
  серверную сетку слотов. Перед записью доступность проверяется повторно.
- Подтверждённая новая встреча появляется в уже загруженном видимом периоде сразу;
  успешное удаление убирает карточку до завершения повторного чтения списка.
  Неизвестный исход по-прежнему обрабатывается журналом, без слепого повтора.
- После создания в другом периоде сохраняется прежний переход к дате встречи.
  Уточнение полной карточки сервером не вызывает второй анимации собственного
  создания. Сравнение учитывает алиасы вхождений, у новой еженедельной встречи
  формируется виртуальная идентичность первого вхождения.
- Плашка свежести скрыта при нормальной связи, появляется при ошибке/потере связи;
  кнопка обновления в боковой панели остаётся. Перенесён коммит `5d8d646` без
  создания нового коммита. В desktop скрыт дублирующий footer календаря;
  нижний блок боковой панели уплотнён. В прототипе footer сохраняется по умолчанию.
- Исправлено повторное открытие карточки: новый выбор получает отдельный ключ
  компонента, чтобы закрытый нативный dialog не переиспользовался без showModal.
  Сбой воспроизведён Electron-сценарием; снятые события подтвердили, что клик
  доходил до выбора, но в DOM оставался dialog с open=false.

Напоминания, аналитика, гейт операций серий и поддержка алиасов из main сохранены.
Исторический подробный план кэша остаётся в архиве; актуальный итоговый отчёт
не заменён старым планом. Оставшиеся различия архива с main содержат старые версии
и тесты, заменённые при интеграции, а не отдельные новые функции.
