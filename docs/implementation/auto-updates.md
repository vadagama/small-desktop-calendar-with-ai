# Обновления календаря

Ordo получает подписанные стабильные обновления из публичных GitHub Releases
репозитория `vadagama/small-desktop-calendar-with-ai`.

## Поведение и критерии приёмки

- Проверка через 10 секунд после запуска и каждые 4 часа, независимо от входа
  в Small. Повторные запросы во время проверки или скачивания объединяются.
- Настройки модели → «Обновления»: текущая версия, проверка вручную, описание
  выпуска обычным текстом, прогресс, ошибки и повторная попытка.
- Доступная версия скачивается автоматически. Установка только после явного
  подтверждения перезапуска; «Позже» скрывает уведомление до следующего запуска.
  Обычный выход не устанавливает обновление.
- Перед перезапуском пользователь предупреждён о несохранённых изменениях.
- При обновлении сохраняются локальный профиль, настройки, сессия, ключи и контекст.
- Wails проверяет фиксированный URL манифеста, подпись и контрольную сумму архива.
- Локальные и dev-сборки показывают, почему автообновление недоступно.

## Ordo на Wails

Автообновление включается в стабильной сборке arm64, подписанной Developer ID
и прошедшей Gatekeeper, при запуске с обычным профилем. Первая установка
стабильной сборки после локального RC выполняется через DMG. При выпуске
используй один и тот же ключ Ed25519, чтобы установленные версии могли
проверять подписи новых архивов.

`npm run package:wails:mac -- --release --notes <файл>` готовит три файла для
GitHub Release `vX.Y.Z`:

- `Ordo-X.Y.Z-arm64.dmg` для установки.
- `Small-Calendar-Wails-X.Y.Z-arm64.zip` для автообновления.
- `latest-wails-mac.json` с версией, SHA-256, подписью Ed25519 и URL архива.

Отметь стабильный выпуск как Latest в GitHub и проверь выдачу
[`latest-wails-mac.json`](https://github.com/vadagama/small-desktop-calendar-with-ai/releases/latest/download/latest-wails-mac.json)
и ZIP без авторизации. Тест `TestWailsUpdaterStagesSignedGitHubRelease`
повторяет загрузку по этим адресам с имитацией перенаправлений GitHub, а также
проверяет отказ при изменённой подписи и несовпадении размера.
