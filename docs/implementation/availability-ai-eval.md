# Проверка понимания запросов доступности

9 ноября 2026. Реальная настроенная модель: `deepseek-flash`, OpenAI-compatible SDK, стандартные инструкции приложения, фиксированное время 09.11.2026 10:00 Asia/Almaty. Каталог, память, аккаунт и все инструменты синтетические. Секрет разрешён в main-профиле, но не выводится и не попадает в фикстуры.

Команда из корня:

```sh
node --import tsx scripts/eval-availability.mjs --configured-profile
```

Альтернатива — переменные `AVAILABILITY_EVAL_BASE_URL`, `AVAILABILITY_EVAL_MODEL`, `AVAILABILITY_EVAL_API_KEY`; не записывать их значения в репозиторий. `AVAILABILITY_EVAL_CASE` ограничивает прогон одним id. Без профиля скрипт возвращает unavailable и exit 2, не объявляя успех. Состав сравнивается точно; организатор всегда добавляется первым по актуальному требованию пользователя.

| Случай                      | Ожидаемое действие                                                            | Результат |
| --------------------------- | ----------------------------------------------------------------------------- | --------- |
| week-names                  | Организатор + Анна + Иван, неделя 09.11, 60 минут                             | passed    |
| tuesday-group               | Организатор + сохранённая группа «Тимлиды», 10.11, день, 60 минут             | passed    |
| tomorrow-half-hour          | Анна + текущий пользователь, 10.11, 30 минут                                  | passed    |
| negative-count              | подсчёт встреч не открывает доступность                                       | passed    |
| ambiguous-person            | «Саша» с двумя совпадениями не открывает панель с выдуманным составом         | passed    |
| followup-thursday-half-hour | Организатор + текущий состав панели Анна + Иван, уточнение на 12.11, 30 минут | passed    |

Итого **6/6**. Набор: `tests/fixtures/availability-prompts.json`. Организатор закрепляется приложением, не решением модели и не через поиск самого пользователя. Сохранённая группа применяется через useGroup с проверкой каталога. Для отсутствующей группы и неполной выдачи нельзя объявлять первую страницу полным составом роли.

Это выборочная семантическая проверка конкретной модели, а не гарантия для любого промпта и провайдера. Детерминированные проверки прав, схем и доставки выполняются отдельно; поиск не создаёт встреч и не сохраняет память.
