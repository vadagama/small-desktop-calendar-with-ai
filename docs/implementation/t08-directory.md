# T08 — Каталог участников, первый срез

`CalendarService.searchPeople({accountId, query, page})` читает одну страницу
поиска сотрудников Small. Он возвращает `people` (ID участника, имя, должность),
`page` и `nextPage`; при последней странице `nextPage` равен `null`.
Основание — [проверка текущего клиентского контракта](../research/team-small-api.md).

Сервис использует существующий `readCalendar`: проверка текущего аккаунта,
обновление сессии и отклонение ответа после выхода остаются на общей границе.
Разрешён только GET `/gate/employee/api/search/persons` с тремя проверенными
параметрами. Чтение ответа ограничено существующим лимитом 8 MiB. Лишние поля
сотрудника отбрасываются, некорректные записи, повторные ID и противоречивая
пагинация отклоняются. Однофамильцы сохраняются отдельными кандидатами.

Метод подключён к IPC и [диалогу подбора](t08-availability.md).
Инструмент ассистента пока не подключён. Автоматический выбор человека и вывод о полном
составе команды по результатам поиска не выполняются.

## Проверки 29 октября 2026 года

- Шесть новых тестов сначала падали без реализации, затем прошли.
- Полный `npm test`: 59 тестов прошли.
- `npm run typecheck`, `npm run build`, `npm run format:check`: прошли.
- `npm run build:desktop`: прошла с существующими предупреждениями `use client`
  в SWR/lucide. Упаковка `.app` отдельно не выполнялась.
- `npm run test:desktop`: все 6 существующих Electron E2E прошли. Они проверяют
  регрессии календаря, чата, компоновки, профилей и изоляции окна; новый поиск
  каталога покрыт сервисными тестами, поскольку UI для него ещё не подключён.

Тесты используют только синтетических сотрудников. Реальный авторизованный
поиск и поведение пустой серверной страницы пока не проверены: неизвестная
форма ответа будет ошибкой, а не утверждением, что сотрудников нет.
