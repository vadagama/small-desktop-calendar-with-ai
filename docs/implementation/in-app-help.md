# Руководство в приложении

Раздел «Помощь» открывается по иконке вопроса слева. Он заменяет рабочую область
календаря оглавлением и статьёй, сохраняя смонтированные календарь и ассистента,
дату, раскладку, переписку и черновик. Тема и поиск сохраняются до закрытия окна
приложения. Настройки и память открываются поверх руководства.

## Состав

- Общий React-компонент: `src/renderer/ui/Help.tsx`, `help.css`, `help-types.ts`.
- Desktop-тексты: `src/renderer/help-content.ts`; демонстрационные тексты остаются
  в `prototype/src/help-content.ts`. Прототип использует тот же компонент.
- Десять уроков в трёх главах: знакомство, планирование с AI, персональные настройки.
- Поиск по заголовкам, шагам, пояснениям и примерам; пустой результат со сбросом.
- Локальные изображения с подписями, alt-текстом и увеличением.
- Последовательная навигация между уроками с переводом фокуса на заголовок.

## Интерактив

«Подставить запрос» передаёт одноразовое сообщение в существующий DesktopAssistant.
Текст добавляется к черновику и получает фокус. Вызов модели не выполняется;
отправка, подтверждение памяти и операций календаря остаются штатными.
Если добавление превысит лимит поля 2000 символов, черновик сохраняется целиком,
а уведомление предлагает его сократить и повторить подстановку.

Действия статей — фиксированный типизированный список, без произвольных URL,
JavaScript, новых IPC-методов или привилегий. Авторизация продолжает проверяться
обычными компонентами. Аналитика desktop-клиента описана как отчёт в ассистенте.

## Изображения и воспроизведение

Изображения входят в `resources/renderer/help/`, копируются сборщиком в renderer
и загружаются через `small-app://workspace/`. Внешние сервисы не нужны.
Все изображения содержат только синтетические данные:

- `workspace.png`, `event.png`, `memory.png`, `settings.png`: после
  `npm run build:desktop` выполнить `node --import tsx scripts/capture-help.mjs`.
  Скрипт создаёт отдельный профиль, подменяет Small API и удаляет профиль по завершении.
- `analytics.png`: снимок `test-results/desktop/analytics.png` из
  `tests/desktop/analytics.spec.ts`.
- `slots.png`: снимок `test-results/desktop/meeting-draft.png` из
  `tests/desktop/calendar-assistant.spec.ts`, показывающий черновик после выбора времени.

Скриншоты не являются настройками или памятью пользователя и не заполняют профиль.

## Проверка

- `npm run typecheck`, `npm test`, `npm run build:desktop`, `npm run check:size`.
- `npm run test:desktop -- tests/desktop/help.spec.ts`: руководство без входа,
  поиск, все изображения, размеры текста, переходы, сохранение черновика,
  отсутствие отправки, переполнение поля, чистые логин/пароль и инструкции.
- `npm run test:desktop -- tests/desktop/layout.spec.ts tests/desktop/window.spec.ts`:
  раскладка, сохранение состояния и безопасность renderer.
- `npm --prefix prototype run test:ui`: регрессии общего компонента в прототипе.
- Пакет проверяется теми же desktop-тестами через `SMALL_APP_EXECUTABLE`.

Локальная сборка: `node scripts/package-mac.mjs --local-sign --out release/guide`
после сборки Electron. Запускать с новым `--user-data-dir`, сохраняя пользовательские
профили. Пакет предназначен для локальной проверки, не для внешней дистрибуции.

После «С чего начать» расположены «Аутентификация» и «Настройка LLM»: пошаговое заполнение форм, проверка результата и снимки настоящих окон без учётных данных. В desktop кнопки открывают вход Small и настройки модели; в веб-прототипе эти два урока иллюстрируют desktop без подключения сервисов. Скрипт capture-help.mjs также снимает auth.png и llm.png.

Раздел «Настройка уведомлений» описывает напоминания Small, проверку доставки, разрешения macOS и фокусирование. Источники Apple: https://support.apple.com/ru-ru/guide/mac-help/mh40583/mac и https://support.apple.com/ru-ru/guide/mac-help/mchl613dc43f/mac. Снимок notifications.png создаётся capture-help.mjs без отправки уведомления и изменения системных настроек.
