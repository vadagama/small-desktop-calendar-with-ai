# Выбор времени встречи

В создании и редактировании события время можно ввести в формате `ЧЧ:ММ` либо
выбрать из списка с шагом 15 минут. Произвольное минутное значение сохраняется
и тоже появляется в списке. При открытии видно текущее значение.

Стрелки вверх/вниз открывают список и перемещают выбор, Enter применяет время,
Escape закрывает список, сохраняя диалог события. Щелчок вне списка закрывает его.
Список отображается поверх прокручиваемой формы через HTML Popover API:
https://developer.mozilla.org/en-US/docs/Web/API/Popover_API/Using.

Под датой и временем расположены кнопки «15 мин», «Полчаса», «Час», «Полтора»,
«2 часа». Нажатие рассчитывает окончание от текущего начала. Кнопка выбранной
длительности отмечена; ручное изменение времени обновляет отметку. При пустом
или некорректном начале кнопки недоступны. Ручное изменение начала само по себе
не меняет окончание: для пересчёта нужно нажать кнопку длительности.

Интервал через полночь заканчивается на следующий день, что явно подписано
в форме. Существующий предел длительности — 8 часов — сохраняется. Расчёт
использует Asia/Almaty. Подтверждение занятости и ограничения рабочих часов Small
продолжают действовать: кнопки длительности не обходят эти проверки.

Проверка: `npm test`, `npm run typecheck`, `npm run build:desktop`,
`npx playwright test -c playwright.desktop.config.ts tests/desktop/meeting-time.spec.ts tests/desktop/calendar-create.spec.ts tests/desktop/meeting-create.spec.ts`.
