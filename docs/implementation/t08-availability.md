# T08 — Выбор участников и подбор общего времени

> Исторический отчёт: отдельное окно «Общее время» и кнопка его открытия
> удалены из desktop. Подбор через AI-чат и проверка времени в форме создания
> встречи сохраняются. Описанный ниже E2E удалён вместе с этим окном.

Кнопка «Подобрать время» в заголовке desktop доступна после входа в Small.
Диалог позволяет найти сотрудников постранично, явно выбрать каждого человека,
указать дату и длительность (30 минут по умолчанию), затем запросить варианты.
Пользователь включает себя в состав самостоятельно: ID профиля Small не
подменяется неподтверждённым ID участника. Поиск полного состава команды
по названию подразделения не реализован.

## Поведение

- Однофамильцы представлены раздельно с должностью и ID. Выбранные люди
  сохраняются при смене запроса или страницы; никто не исключается автоматически.
- Подбор ограничен выбранным рабочим днём в `Asia/Almaty`. Выходные отклоняются;
  неизвестный горизонт серверного поиска не выдаётся за гарантированный диапазон.
- Сначала читаются серверные слоты, затем занятость всех выбранных людей на день.
  Нужна отдельная запись `participant_id` с `busy_slots` для каждого человека.
  Пропущенная, повторная, агрегированная или неизвестная запись — ошибка полноты,
  а не свободное время. Непроверенные варианты формата серверного ответа отклоняются.
- Варианты с пересечениями, неправильной длительностью, в прошлом или за границей
  выбранного дня не показываются. Совпадение конца одной встречи с началом другой
  допустимо. Дубликаты слотов удаляются, результат сортируется по времени.
- Пустой ответ, отказ доступа и неизвестная занятость имеют разные сообщения.
  При изменении даты, длительности или состава старые результаты очищаются.
  Запоздалые ответы после изменения параметров или закрытия диалога игнорируются.
- Escape закрывает нативный modal dialog и возвращает фокус. Выход из аккаунта
  убирает доступ к подбору; содержимое диалога не сохраняется на диск.

## Граница доступа

Renderer получает только `calendar.people` и `calendar.slots` через типизированный
bridge. IPC проверяет отправителя. Main проверяет входные данные и текущий аккаунт;
сессия отклоняет результат после выхода или смены аккаунта. При refresh повторяется
тот же запрос чтения с теми же параметрами.

Два POST-маршрута — `/gate/team/api/calendar/events/find-slots` и
`/gate/team/api/calendar/events/busy-intervals` — разрешены с фиксированными схемами
параметров. `force`, произвольный URL и запись события недоступны через этот путь.
Ключи и токены не передаются в renderer или модель. Проверенные прикладные ошибки
`CalendarError` сохраняются через слой сессии; неизвестные ошибки по-прежнему
заменяются безопасным общим сообщением.

Защитные ограничения клиента: 20 участников, 1–480 минут, 1000 слотов,
5000 интервалов занятости суммарно и 8 MiB на ответ. Это не утверждение о лимитах
Small. UI предлагает длительности 15/30/45/60/90/120 минут. В расчёте даты
интервалов переводятся в числа однократно, объём обработки ограничен.

## Проверки

29 октября 2026 года прошли `npm test` (71 тест), `npm run typecheck`,
`npm run build`, `npm run format:check`, `npm run build:desktop`,
`npm run test:desktop` (7 Electron E2E) и `git diff --check`.
Desktop-сборка сохраняет прежние предупреждения bundler о `use client`
в SWR/lucide; новых зависимостей или изменений lockfile нет.

Новые сервисные тесты проверяют контракт запросов, полноту состава, конфликты,
пагинацию, временные границы, отказ лишних параметров и ограничение объёма.
Регрессионный тест воспроизводит потерю типа и сообщения прикладной ошибки
в слое сессии. Контрольная инверсия проверки конфликта приводит к падению теста;
после эксперимента код восстановлен.

Electron E2E проходит через настоящий preload, IPC, сервис и изолированную
Chromium-сессию; только серверная граница заменена синтетическим Small API.
Проверяются однофамильцы, следующая страница, явный выбор, фильтрация конфликта,
пустой поиск/результат, неизвестная занятость, отказ доступа, очистка результата
при смене длительности/состава, Escape, фокус и блокировка после выхода.
В тесте нет ошибок или предупреждений renderer. Снимки диалога на 900×640
просмотрены; содержимое прокручивается, результат и действия доступны.
Chrome DevTools MCP недоступен; проверка выполнена Playwright в Electron.

## Ограничения

Реальные авторизованные ответы Small, правила полноты занятости и каталога
по-прежнему требуют проверки. Текущий контракт восстановлен по публичному
клиенту; строгие схемы намеренно принимают только подтверждённый поднабор.
Например, агрегированная занятость, алиасы `resource_id`/`id`, timestamps без
UTC-offset и дополнительные поля ответа не считаются подтверждением свободы.
Синтетический успех не закрывает эти интеграционные проверки.

Вызов подбора из AI-чата реализован [отдельным срезом](t08-assistant-tools.md).
Определение полного состава команды остаётся открытым. Диалог не создаёт и не резервирует встречи; перед
созданием нужна повторная проверка занятости. Упакованная `.app` отдельно
для этого среза не проверялась. Новых зависимостей нет.
