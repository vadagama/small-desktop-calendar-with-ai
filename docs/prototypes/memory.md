# Экран памяти в прототипе

Экран открывается кнопкой с мозгом «Память ассистента» в нижней группе бокового меню.
Рядом — кнопка с искрами «Настройки AI-помощника», затем настройки пространства
и профиль. Кнопки доступны и при скрытой панели ассистента. На узком экране
сначала нужно открыть навигацию. Основание —
[требования к памяти](../proposals/assistant-memory.md).

## Возможности макета

- Предпочтения: длительность, начало и конец временного диапазона, перерыв.
  Есть редактирование, сброс отдельных полей и проверка диапазона времени.
- Сохранённый контекст: свободные текстовые записи с источником и датой.
  Можно добавить, изменить или удалить запись; пустой текст отклоняется.
  Имя, должность и прозвище не являются обязательными полями карточки.
- Иконка мозга используется в заголовке контекста и на кнопках открытия памяти.
- Очистка всей памяти требует подтверждения; предусмотрены пустое состояние
  и сообщения об успешном действии.
- Все люди и значения демонстрационные. Состояние сохраняется при повторном
  открытии экрана в этой вкладке и сбрасывается при перезагрузке страницы.

Макет не подключён к реальному хранилищу, календарным предпочтениям и LLM.
Архива чатов на экране нет; он остаётся в бэклоге. Группы и форматы встреч
не включены в этот срез прототипа.

Окно «Настройки AI-помощника» демонстрирует выбор стиля общения и ввод
инструкций с сохранением до перезагрузки страницы. Эти настройки пока не влияют
на демонстрационные ответы ассистента.

## Проверки

30 октября 2026 года выполнены команды из `prototype/package.json`:

- `npm test`: 12 unit-тестов прошли.
- `npm run test:ui -- --workers=2`: 30 браузерных тестов прошли, включая
  добавление/редактирование/удаление контекста, проверку пустого текста,
  повторное открытие, отмену/подтверждение очистки, сброс поля,
  возврат фокуса по Escape и окно шириной 390 CSS px.
- `npm run build`: TypeScript и Vite прошли; Vite сообщает предупреждения
  о директиве `use client` в lucide-react.
- Prettier для изменённых файлов и `git diff --check` прошли.

Прототип отдельно открыт в Electron 45.1.0 в изолированном профиле:
computed font-size заголовка — 18 px, текста записей — 13 px,
поля ввода — 14 px. В окне 1440×960 экран помещается без внутренней прокрутки;
ошибок JavaScript в проверенном сценарии нет. Для ширин 320/768/1024/1440 CSS px
проверено отсутствие горизонтального переполнения; текстовое поле записи — 14 px. Это проверка прототипа в Electron,
а не внедрение памяти в рабочее desktop-приложение.

## Подключение к desktop-приложению

Рабочая форма Electron использует компоненты предпочтений и текстовых записей
прототипа, подключённые к IPC вместо демонстрационных данных. В неё добавлены
группы и форматы. Кнопки памяти с мозгом и настроек AI-помощника находятся в
боковом меню. Сам браузерный стенд продолжает работать с демонстрационными данными.
См. [реализацию и проверки](../implementation/assistant-memory.md).
