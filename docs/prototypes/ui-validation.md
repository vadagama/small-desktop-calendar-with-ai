# Стенд для валидации UI

Статус: согласован пользователем 28.10.2026 как основа UI для разработки.
Основание согласования: «Можно этот прототип брать в работу».
Согласование относится к интерфейсу и взаимодействиям; реализация плана T01–T13
и выбор десктопной оболочки остаются отдельными решениями.
Основание: запрос пользователя «Подготовь прототип приложения для валидации UI»
и сценарии docs/discovery.md. Все встречи и люди синтетические.

## Проверяемые сценарии

1. Открыть неделю 26 октября — 1 ноября 2026, перейти между периодами,
   переключить день/неделю/месяц, отфильтровать календари и открыть событие.
2. Разместить календарь и ассистента рядом/вертикально в обоих порядках,
   поменять их перетаскиванием заголовка, изменить размер разделителем
   мышью или стрелками. Компоновка сохраняется локально.
3. В ассистенте выбрать демонстрационный запрос, получить доступные слоты,
   выбрать вариант, проверить итоговую карточку и явно добавить демо-встречу.
4. Создать демонстрационную встречу вручную; отменить её из карточки.
5. Увидеть загрузку, пустое состояние, сетевую ошибку и отказ доступа
   через настройки стенда; повторить загрузку после ошибки.
6. Проверить малое окно, клавиатурную навигацию и отсутствие console errors.

## Границы

React + TypeScript + Vite служат временным браузерным стендом. Десктопная
оболочка не выбирается этим изменением. API, LLM, авторизация, Keychain,
нативные уведомления, повторяющиеся серии и проверка реальной занятости
не реализованы. Сообщения ассистента детерминированы. События живут в памяти;
перезагрузка очищает изменения. Сохраняется только компоновка, не встречи/чат.
Недельная сетка показывает все семь дней. Время демо-событий — 08:00–18:00;
прототип не реализует полный паритет настроек производственного календаря.

## Запуск

Из prototype/: `npm ci`, затем `npm run dev`.
Адрес: http://127.0.0.1:5173.
Проверки: `npm test`, `npm run build`; браузерные сценарии: `npx playwright test`.

Документация инструментов: [Vite](https://vite.dev/guide/),
[React](https://react.dev/learn/creating-a-react-app).

## Direction contract

THESIS: Календарь и ассистент используют визуальный язык Small из присланного
пользователем скриншота. Главная задача — проверка знакомого интерфейса
и гибкой компоновки.

OWN-WORLD: Белые поверхности; светло-серая узкая навигация; чёрные основные
действия; оранжевый знак; голубые заполнения и контуры событий. Тонкие линии
сетки, компактный системный sans-serif. Официальные токены/компоненты Small
не предоставлены: визуальная реконструкция по скриншоту, не импорт библиотеки.

STORY: Пользователь читает неделю, открывает событие или обращается
к ассистенту; подтверждение добавляет демонстрационное событие.

FIRST VIEWPORT: Узкая иконная панель 56px, боковая панель дат 200px,
семидневный календарь и ассистент с изменяемыми пропорциями. «Создать» справа
вверху. Signature interaction: живое изменение размеров и порядка панелей
без потери даты и разговора. В узком окне — вертикальная компоновка.

FORM: Явный референс пользователя Small заменяет первоначальное направление
seed:e3c2d5b498c46669. Реализация непосредственно в коде, без растровых ассетов.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Результат проверки

- `npm test`: 5 проверок дат и демонстрационных слотов проходят.
  Изменение условия пересечения намеренно ломает тесты; исходное условие восстановлено.
- `npm run test:ui`: 9 сценариев проходят, включая четыре компоновки,
  resize мышью/клавиатурой, сохранение, перестановку перетаскиванием,
  создание/подтверждение/отмену, состояния и ширины 320/768/1024/1440px.
- `npm run build`: TypeScript и сборка проходят. Vite выводит два
  предупреждения про `use client` внутри lucide-react; стенд полностью клиентский.
- `npm run format:check` и `git diff --check` проходят.
- В in-app browser нет сообщений error/warn. Скриншоты desktop/mobile
  проверены; независимое ревью подтвердило исправления организатора и разделителя.
- Проверки реальных API, LLM, native macOS и полного WCAG-аудита не проводились.

Для браузерных тестов после `npm ci` один раз установить тестовый браузер:
`npx playwright install chromium --only-shell`, затем `npm run test:ui`.
Требуется Node.js 22.12 или новее. При ширине меньше 760px панели идут
вертикально; семидневная сетка прокручивается горизонтально внутри календаря.
В вариантах «Слева/Сверху» Tab-порядок остаётся календарь → ассистент;
это известное ограничение прототипа для последующей проверки доступности.

## Перетаскивание событий

В видах «День» и «Неделя» перетаскивание середины события меняет время
и день; верхнего/нижнего края — начало/окончание. Шаг 15 минут,
минимальная длительность 15 минут, границы 08:00–18:00.
Пересечение по демо-участникам отклоняется с уведомлением.
В месячном представлении перетаскивание пока не реализовано.
Дублирующая кнопка «Компоновка» убрана; настройки доступны в боковой панели.
