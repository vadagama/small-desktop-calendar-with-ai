# Переход Small Desktop Calendar на Go и Wails

Цель — уменьшить размер пакета и число зависимостей, ускорить работу приложения и тестирование. Целевой стек — Go и Wails для приложения, React/TypeScript и shadcn для компонентов, текущая дизайн-система и Dockview Community для компоновки.

Главный показатель — размер установочного DMG для macOS arm64. Ориентир — до 15 МБ для полной сборки с рабочим ассистентом и его рантаймом. Достижимость проверяется упаковкой и замером.

Ассистент остаётся на TypeScript и действующей версии Vercel AI SDK Core + UI. В Go переходят календарные и прикладные сервисы, к которым обращаются его инструменты.

Исходная ветка `codex/all-calendar-updates`, ревизия `776bdd54f9880bd51dbcf89c309711b21b139379`. Проверки проведены с локальными изменениями создания встреч. Хост — Electron, интерфейс использует Dockview, ассистент — Vercel AI SDK. В этой копии хранилища используют файлы профиля. Миграция сохраняет файловое хранение. SQLite рассматривается отдельно, если появится подтверждённая потребность.

Для итогового сравнения включать в обе сборки работоспособного ассистента и его зависимости. Фиксировать размер .app и DMG, время холодного старта до интерактивности, суммарную память процессов приложения в простое, задержку чтения календаря, прямые и транзитивные зависимости отдельно по runtime и dev, длительность чистого и повторного прогона эквивалентных тестов. Сравнивать одинаковые сценарии, архитектуру, комплектацию и тестовые данные. Итоги оформлять с измеренными значениями.

Для завершения перехода внешний вид и поведение UI должны совпадать с исходной версией. Все сохраняемые данные пользователя переносятся с сохранением значений, связей и изоляции аккаунтов. Сверка охватывает настройки, профили, память, группы, форматы встреч, локальный кеш и журналы операций. Сохранение состояния входа и ключей моделей проверяется на синтетических профилях с действительными тестовыми сессиями и ключами. Отдельно инвентаризировать временное состояние окна и черновики и зафиксировать текущее поведение при перезапуске.
