# Типографика и плотность интерфейса

Приложение использует компактную desktop-типографику. Размеры ниже указаны
в CSS px при масштабе 100%; пиксели Retina-скриншота не равны CSS px.
Единый источник размеров — токены `:root` в `prototype/src/styles.css`.

| Элемент | Токен | Размер |
| --- | --- | --- |
| Вторичные метки, календарные подписи | `--font-caption` | 11 px |
| Выпадающие и контекстные меню, текст тултипа | `--font-menu` | 12 px |
| Участники, компактные карточки, текст уведомлений | `--font-compact` | 13 px |
| Основной текст, поля и кнопки форм, дата события | `--font-body` | 14 px |
| Заголовок диалога | `--font-dialog-title` | 18 px |

Заголовок тултипа и уведомления — `--font-body`, без увеличения до заголовка
диалога. Меню: обычное начертание 400, line-height 1.35, внутренние отступы
пункта 10px 12px. Длинные названия переносятся, шрифт не увеличивается.
Системный шрифт наследуется из корня. Не применять zoom/transform для уменьшения
текста и не отключать пользовательское масштабирование.

Для новых и изменяемых компонентов использовать токен по роли элемента.
Старые экраны переводятся на токены при их изменении; этот документ не означает,
что все старые литералы уже заменены. Не вводить новую шкалу в отдельном компоненте.
Проверять computed font-size, длинный русский текст, меню поверх диалога и узкое
окно; размеры на макете оценивать с учётом devicePixelRatio и масштаба.
