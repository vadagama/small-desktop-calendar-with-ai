# Вход в Small

Профиль открывается через аватар внизу боковой панели и кнопки в сообщениях о входе.
Постоянный индикатор входа — точка у аватара; в шапке статуса нет.
Незаполненная форма содержит логин, пароль с переключением видимости и кнопку
«Войти в Small». Пароль очищается после отправки и при закрытии диалога.
При отправке читаются фактические значения полей, включая автозаполнение,
которое могло не вызвать событие React.

## Состояния

| Состояние             | Отображение                                                                                                           |
| --------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Проверка              | «Проверяем вход…», действия в форме входа недоступны                                                                  |
| Подтверждённая сессия | «Вход подтверждён», имя, логин и время последней успешной проверки в Asia/Almaty                                      |
| Нет сессии            | Форма входа и инструкция для календарных операций                                                                     |
| Истечение сессии      | Предупреждающая точка у аватара, инструкция с кнопкой входа в календаре, ассистенте и открытой форме создания встречи |
| Ошибка проверки       | «Сессия не проверена», причина ошибки и повторная проверка; сохранённый профиль остаётся доступным                    |

Зелёный статус появляется только после успешного ответа сервера при проверке
профиля. Состояние синхронизации календаря отображается независимо от входа.
Ошибка сети и отказ в доступе к отдельному ресурсу не означают истечение сессии.

Проверка выполняется при запуске, вручную, при восстановлении сети, а также
при возвращении в окно и каждую минуту в видимом приложении. Фоновые проверки
при фокусе и по таймеру ограничены одной попыткой в минуту. Проверки и операции
входа в интерфейсе не выполняются одновременно.

## Истечение сессии

Main сообщает `small-auth:required` без пароля, cookie, токена или профиля.
Preload предоставляет только подписку `smallAuth.subscribeRequired`, возвращающую
функцию отписки. Сигнал поступает при отсутствии сессии, неуспешном восстановлении
после 401 и при 401 записи или загрузки вложения. Обычный 403 ресурса этот сигнал
не вызывает. Фоновая проверка завершённой сессии не разблокирует операции:
для этого требуется подтверждённый сервером вход.

Чтение может обновить сессию и повториться. Создание, изменение, удаление,
ответ на приглашение и загрузка вложений автоматически не повторяются.

Открытая форма создания встречи сохраняет поля в памяти до повторного входа
в тот же аккаунт. Отправку пользователь продолжает явно. При смене аккаунта
или явном выходе форма закрывается. Вложения неотправленного черновика после
повторного входа нужно прикрепить заново: разрешение на них связано с ревизией
сессии. Неизвестный результат уже отправленной операции сохраняется для сверки.

## Проверка

- `npm run typecheck`
- `npm test`
- `npm run build:desktop`
- `npx playwright test -c playwright.desktop.config.ts tests/desktop/auth-states.spec.ts tests/desktop/small-auth.spec.ts tests/desktop/calendar-resilience.spec.ts tests/desktop/meeting-create.spec.ts tests/desktop/calendar-assistant.spec.ts`

Desktop-тесты используют изолированный профиль Electron и синтетический Small;
запросы к рабочему серверу заблокированы. Они проверяют пустую форму, вход,
видимость и автозаполнение пароля, типографику, сетевой сбой, восстановление сессии и черновика,
а также блокировку записи при фоновой перепроверке истёкшей сессии.
